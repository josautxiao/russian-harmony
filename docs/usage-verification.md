## 移调

第 52 号上排「开放 1」的两拍 T–D，从 C 大调移至 D 大调。每列各占一拍，音高顺序为女高、女低、男高、低音。

| | T | D |
|---|---|---|
| C 大调，原谱 | C5 / E4 / G3 / C3 | B4 / D4 / G3 / G2 |
| D 大调，移调示范 | D5 / F♯4 / A3 / D3 | C♯5 / E4 / A3 / A2 |

八个音均上移两个半音，男高保留 A3。两和弦各重复根音，保持开放排列。六对声部均已复算。

## 原创书面题

G 大调，3/4，四小节。为给定女高写四部和声，只用原位 T、S、D。根音相距四、五度时采用第 52 号的和声连接。第二小节后半用 S，第四小节结束在 T。

~~~text
G4h F♯4q | G4q G4h | G4h F♯4q | G4h.
~~~

参考答案按女高、女低、男高、低音列出。

| 小节 | 时值 | 功能 | 四声部 |
|---|---|---|---|
| 1 | 二分 | T | G4 / D4 / B3 / G2 |
| 1 | 四分 | D | F♯4 / D4 / A3 / D3 |
| 2 | 四分 | T | G4 / D4 / B3 / G2 |
| 2 | 二分 | S | G4 / E4 / C4 / C3 |
| 3 | 二分 | T | G4 / D4 / B3 / G2 |
| 3 | 四分 | D | F♯4 / D4 / A3 / D3 |
| 4 | 附点二分 | T | G4 / D4 / B3 / G2 |

每小节三拍，每个和弦均原位并重复根音。T–D 保留女低 D4，T–S 保留女高 G4，其余活动上声部级进。两处 D–T 的女高 F♯4 都上行至 G4。六对声部逐连接复算，未见平行纯五度、平行八度或外声部直进纯五、八度。

## 等音转调的调用复测

**查例请求**　找一条从大调出发，把属七和弦重拼为新调的变音重属，再接终止四六的四部示范。由技能入口沿教材 B 索引进入[主题 58](../references/dubovsky/ch58.md)。取 B-846 第 3 组，印刷第 404 页（PDF 400）的最下行。原印 C-dur 到 As-dur，第一小节末的 E₇ 实奏由下到上为 E3、G♯3、D4、B4。按新调等音解释是 F♭、A♭、D、C♭。原谱下一小节首拍标 K₆₄，随后标 D₇，末格标 T。第二格女低 E♭4 保持至第三拍。

**移调请求**　将这三小节整体上移大二度，改为 D 大调到 B♭ 大调。按原谱时值存录，q 为四分，h 为二分，点为附点，~ 为同音延长。

~~~text
S D5q C♯5h | D5h C5q | B♭4h.
A F♯4q E4h | F4h~ F4q | F4h.
T A3q B3q A♯3q | B♭3q A♮3q E♭4q | D4h.
B D3q G3q F♯3q | F3h. | B♭3h.
~~~

逐音比较原谱与移调结果的 22 个事件，均上移两个半音及一个字母音级，保留原节奏与女低延音。第一小节末 F♯₇ 的四声部可按新调重拼为 D♭5、E4、B♭3、G♭3，键位完全相同。G♭3 下行至 F3，E4 上行至 F4。

**原创题**　G 大调转 E♭ 大调，3/4，四小节。为给定女高写四部和声。首小节用一次属到主确立 G 大调。第 2 小节用 G 大调语境中的 B₇，写出改作 E♭ 大调变音重属的等音拼写。第 3 小节前两拍用 K₆₄，末拍用 D₇，末小节落在主和弦。

~~~text
B4q A4q G4q | F♯4h. | G4h F4q | E♭4h.
~~~

以下为一份参考配法，音高按女高、女低、男高、低音排列。

| 小节与拍位 | 功能 | 四声部 |
| --- | --- | --- |
| 1，第 1 拍 | G 大调 T | B4 / D4 / G3 / G2 |
| 1，第 2 拍 | G 大调 D₆₅ | A4 / D4 / C4 / F♯2 |
| 1，第 3 拍 | G 大调 T | G4 / D4 / B3 / G2 |
| 2，全小节 | B₇，随后按 E♭ 大调改拼 | F♯4 / D♯4 / A3 / B2，可等音改写为 G♭4 / E♭4 / A3 / C♭3 |
| 3，第 1–2 拍 | E♭ 大调 K₆₄ | G4 / E♭4 / B♭3 / B♭2 |
| 3，第 3 拍 | E♭ 大调 D₇ | F4 / D4 / A♭3 / B♭2 |
| 4，全小节 | E♭ 大调 T | E♭4 / E♭4 / G3 / E♭3 |

增六 C♭3–A3 向外半音解决到 B♭2–B♭3。新调属七的 D4 上行至 E♭4，A♭3 下行至 G3。四个小节均为三拍。复算七个和弦、六次连接的 36 对声部关系，未见平行纯五度、平行八度或外声部同向进入纯五度、八度。
