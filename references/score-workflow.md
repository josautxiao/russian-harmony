# 谱例与习题使用指南

适用于阿贝佐娃《Гармония》（A，2008）和四作者合编《Учебник гармонии》（B，1965）。可从 [A 章索引](abyzova/index.md)、[B 章索引](dubovsky/index.md)或[两书主题对照](source-map.md)进入。例号在两书间可能重复，引用时请写 A-080、B-052 等完整编号。页码需区分印刷页和对应参考扫描的 PDF 页。

## 怎样从原谱建立记录

1. 用俄文 OCR 检索正文、题文和例号，读上下文确定谱例在论证什么。用扫描页逐图辨读谱号、调号、拍号、符头、加线、临时记号、符干、连线和原书的正误标记。
2. 作品例记录曲目、片段与教材用来说明的音响或进行，能对照作品谱时注明对应位置。写作示范重点记录四部位置、配置、时值、功能和适用条件。钢琴、书面和口头题分别保留题意，带谱题尽量保留指定条件、给定音与留空。
3. 将可辨内容写成音名与八度、时值和按小节或音响分组的文本。四部通常按 S/A/T/B 列出，中央 C 是 C4。常见记号为 `q` 四分、`e` 八分、`h` 二分、`w` 全音，点为附点，`~` 为同音延长。也有以四分拍计的 `音名:时值` 和只列和弦音的条目，读时以该章图例为准。
4. 对疑点放大原图，按声部对位、同页符形和小节时值复核。有资料时对照同版另一扫描或可定位的作品谱，再记录人工复核和订正依据。拍数吻合可以帮助发现错读，单凭拍数补出的音或记号仍需标明是推导。

覆盖为 A 的 1–773 号、B 的 1–859 号及 B 的 14 条综合附录题。这里的覆盖指编号与章节均有定位，含已知底本缺项。作品分析常只摘取与教学问题有关的段落，谱例的逐音记录细度随条目而异。[A 核验与勘误](../docs/a-verification.md) · [B 核验与勘误](../docs/b-verification.md)

## 原书存疑处怎样使用

| 例子 | 处理方式 |
|---|---|
| A-428 | 印刷第 202 页的括号音组无法确认，转写略去该组。需要还原括注时查清晰底本。 |
| B-047、B-054、B-056 | B-047 的原印「4」由前后 46、48 定位为印刷错误。B-054 保留未印号候选图，B-056 仅保留题文引用。 |
| B-366.9、B-550、B-712 | 将人工订正落到具体音与拍位。B-366.9 首小节记两个二分，B-550 第 7 小节低音 G2 为二分，B-712 第 8 小节女高 F5 为附点二分。 |
| B-421.4 | 第一结尾第 3 小节保留原印的低置 `₂`。含义待定，引用时照录，功能分析勿把它解释成已确认的转位或低音级数。 |
| B-686.2、B-713.4、B-713.9 | 小音符 `x` 表示原题只规定节奏，音高可自行安排。B-713.9 是原书从第 8 条跳至第 10 条的编号缺项。 |

其他带问号或“暂读”的拍位继续保留原有状态。若它会改变移调、排谱、和声分析或答案，先标出影响，再请使用者提供可核对的谱面。可利用已确认的材料编原创变体，并注明采用了哪些给定条件、哪些音由练习自行设定。

## 怎样调用

安装或更新整个仓库文件夹后，在支持 Skill 的客户端调用 `russian-harmony`，或读 [SKILL.md](../SKILL.md) 并保留它到参考文件的相对目录。指定教材或例号、任务、目标调性和所需输出范围。

| 用途 | 可以这样问 |
|---|---|
| 查作品例 | 用 Russian Harmony 查 B-459，说明教材为什么接受这里的五度，并指出涉及的两个声部。 |
| 比较写法 | 查 B-052，列出共同音留在原声部的配置，说明哪些声部级进，以及这个规则适用的连接条件。 |
| 移调 | 把 A-080 第 1 组从 C 大调移到 D 大调，保留节奏和四部位置，列出每个音的音名和八度。 |
| 原创书面题 | 用 B-052 的连接条件为 G 大调写一道四小节原位三和弦配和声题。先给女高题面，再单列参考答案并检查六对声部。 |
| 原创钢琴题 | 参考 B-690 的变音和弦识别与解决，另写四组较易的题，每组给键位，最后附功能与解决。 |

查例时给编号、页码、记录层级与教材的限定条件。移调时检查每个音的拼写、音程、时值和原来的延音关系。原创题可借用某个和声机制，同时改变调性、排列、给定声部或终止位置，题面与答案分列。通过这些记录，可以追查某个和弦怎样进入和解决，比较同一连接的正确配置与反例，并把特定写法转成难度相当的新题。作品中的写法还要结合当时的风格和句法判断。[查例、移调和出题的核验记录](../docs/usage-verification.md)

发布记录主要为中文。页码清单收录参考版的页序和复核状态，原书、扫描图和全文 OCR 需通过各自渠道取得。核验原谱时使用有权访问的相应版本。
