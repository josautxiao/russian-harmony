# B补充：和声分析方法

来源：B主题60《Некоторые вопросы гармонического анализа》，印刷414–428页，PDF410–424。A的练习也包含作品分析，但B把这套方法独立综合。

分析须同时解释听觉、结构与风格，不能止于给每个垂直切片贴罗马数字。先听/读整体，再逐层分析，最后重听以检验解释。

1. 定主要调性与调式，追踪变化并给证据；观察开头和结尾但不只凭最后一个和弦。
2. 定乐句、乐段与终止，分析终止如何分割或延展形式。
3. 单独考察主题旋律的结构、高潮，再解释和声如何支持或改变这些特征。
4. 分析功能与和弦材料，同时考察各声部、低音、音域、配置、织体及其变化。
5. 记录真正换和弦的频率及其变化；分清和声节奏与非和弦音造成的表面活动。
6. 对非和弦音说明准备、解决、冲突和表达作用，对持续音分层处理。
7. 对转调列共同和弦、重释、特征和弦、目标巩固；再归纳全局调性布局。
8. 比较重复主题的和声变奏及时代、作曲家惯例；作品中的特殊手法不直接改写成全体基础习题的许可。

回答格式：整体判断 → 事件/小节表 → 关键声部证据 → 风格与曲式作用 → 不确定项。题目没有谱面或节奏时，不编小节号、具体配音或原书答案。
