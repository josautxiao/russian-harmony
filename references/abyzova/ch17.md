# 主题 17 · 属七和弦及转位解决时的跳进

来源为阿贝佐娃《Гармония》，Музыка，2008。主题始于印刷第 136 页（PDF 70L）。四部依 S/A/T/B 顺序，以 C4 为中央 C。

## A-266 · V2 的跳进解决

印刷第 136 页（PDF 70L）。266а 无调号，C 大调。每对印为二分音符和弦。数字指转位前后各声部的和弦音。

| 组 | 四部 | 跳进 |
|---|---|---|
| 266а.1 | D5/G4/B3/F3 → G5/G4/C4/E3 | 女高五音上跳。 |
| 266а.2 | D5/G4/B3/F3 → G4/G4/C4/E3 | 女高五音下跳，落点女高与女低同音。 |
| 266а.3 | G4/D4/B3/F3 → C5/C4/G3/E3 | 女高根音上跳。 |
| 266а.4 | G4/D4/B3/F3 → C5/G4/C4/E3 | 女高根音与女低五音同时上跳。 |
| 266а.5 | B4/G4/D4/F3 → G5/G4/C4/E3 | 女高从 V2 三音跳到 I6 五音，另印括号内的 C5 作变体。 |
| 266а.6 | G4/D4/B3/F3 → G5/G4/C4/E3 | 女高根音至五音、女低五音至五音，同时跳。 |
| 266а.7 | G4/B3/D3/F2 → C4/C4/G3/E2 | 女高根音下降、男高五音上升，两者同时跳。 |

这一整组低音七音始终 F→E。可把女高固定为 D5 后让学员按第 1–2 组分别向上或向下解决，再检查声部是否会落在同度。

**266б，贝多芬 c 小调第 8 钢琴奏鸣曲《悲怆》第二乐章。** Adagio cantabile，2/4，四个降号，节选在 A♭ 大调。上方五线谱在四降号和拍号后换为低音谱号。以下采用四分音符为 1。

- 首小节女高 `C4:1 Bb3:1`，低音 `Ab2:1 Db3:1`。上谱内声部两拍分别为 `Ab3:0.25 Eb3:0.25 Ab3:0.25 Eb3:0.25` 和 `G3:0.25 Eb3:0.25 G3:0.25 Eb3:0.25`。
- 首小节第 2 拍由 D♭3、E♭3、G3、B♭3 形成 V2。下一小节首拍低音到 C3，女高从 B♭3 跳到 E♭4，构成 I6 的五音落点，所保留的内声部起音是 A♭3，交替 E♭3。可只取这两拍，为另一调写同样的 V2–I6 五音上跳。

## A-267–268 · V43 与 V65 的跳进解决

印刷第 137 页（PDF 70R），c 小调，二分音符和弦。括号内续音为原书给出的旋律接续，单独保留其音值。

| 组 | 四部 | 跳进 |
|---|---|---|
| 267.1 | G4/F4/B♮3/D3 → C5/E♭4/G3/C3 | 女高 1–1。 |
| 267.2 | G4/F4/B♮3/D3 → E♭5/E♭4/G3/C3 | 女高 1–3，括号内续 C5 四分音符。 |
| 267.3 | G4/F4/B♮3/D3 → G5/E♭4/G3/C3 | 女高 1–5，括号内续 C5 四分音符。 |
| 267.4 | B♮4/F4/G3/D3 → E♭5/E♭4/G3/C3 | 女高 3–3，括号内续 C5 四分音符。 |
| 268.1 | D5/F4/G3/B♮2 → G4/E♭4/G3/C3 | 女高 5–5 下跳，括号内续 C5 四分音符。 |
| 268.2 | G4/F4/D4/B♮2 → E♭5/E♭4/G3/C3 | 女高 1–3 上跳，男高 5–5 下跳。 |

V43 所示女高跳进均向上，低音 D3→C3 向下。X 形反向外声部可避开隐伏五八度。原书有时接受重复三音或五音的落点，可用其后括号内的 C5 恢复常见重复方式。V65.2 的双跳用于指定的反向内声部组合。出题可固定 D3→C3 或 B♮2→C3，让学生选用相应的跳进方向与落点。

## A-269–271 · 原位 V7 的根音跳进

印刷第 138 页（PDF 71L），c 小调。各组为二分音符和弦。参与跳进的 V7 均省去五音并重复根音。

| 组 | 四部 | 原书标记与功能 |
|---|---|---|
| 269.1 | G4/F4/B♮3/G3 → C5/E♭4/C4/C3 | V7–i，女高 1–1。 |
| 269.2 | G4/F4/B♮3/G3 → C5/E♭4/G3/C3 | V7–i，女高 1–1，男高导音下行到五音。 |
| 269.3 | G4/B♮3/F3/G2 → C4/C4/E♭3/C3 | V7–i，女高 1–1 下跳。 |
| 269.4 | G4/B♮3/F3/G2 → C4/G3/E♭3/C3 | V7–i，女高 1–1 下跳，女低导音下行到五音。 |
| 269.5 | G4/F4/B♮3/G2 → C5/E♭4/C4/C3 | 原书标「不宜」。外声部同向，两个响位都标 8。 |
| 270.1 | G4/F4/B♮3/G3 → C5/E♭4/C4/A♭3 | V7–VI，女高根音到 VI 三音，上跳。 |
| 270.2 | G4/B♮3/F3/G2 → C4/C4/E♭3/A♭2 | V7–VI，同样的女高和弦音顺序，下跳。 |
| 271.1 | B♮4/F4/G3/G2 → C5/E♭4/C4/A♭2 | 男高根音至 VI 三音，上跳。 |
| 271.2 | F4/B♮3/G3/G2 → E♭4/C4/C3/A♭2 | 男高根音至 VI 三音，下跳。 |
| 271.3 | B♮4/G4/F4/G3 → C5/C5/E♭4/A♭3 | 女低 G4→C5，教材在女低声部标 1–3，落点与女高同度。 |

269 的用途为结尾的强终止。前四组外声部反向，正文允许本处 V7–i 的反向八度。270–271 的 V7–VI 可用于阻碍终止或内部进行。教材指出女低跳进时会发生声部交叉。271.3 的纸本扫描有手写圈，按可见的印刷音头录入。

## 章末习题

印刷第 139–141 页（PDF 71R–72R）。

- **口头。** 分析柴科夫斯基夜曲 Op. 19 No. 4、莫扎特 F 大调奏鸣曲 K. 332 第一乐章及原书所列 c 小调 K. 475 第二部分的 V7 及转位解决。K. 475 的曲类和部分按教材题目原标定位。
- **钢琴 1–2。** 在各调弹转位 V7 的跳进解决。A-273 的给定和弦先辨认，再分别试平稳和跳进解决。
- **钢琴 3–4。** 按 A-274 动机练模进，给 A-275 乐句配和声。
- **钢琴 5–6。** 写、移调并弹奏含 V7 及其转位跳进解决的乐段，再用 A-276 的开头即兴续写。
