# 主题 8　完整功能体系与下属组副三和弦

本主题为印刷 71–83 页（PDF 37R–43R），谱例 132–157，含章末题。音名依中央 C=C4。

### A-132

印刷 71 页（PDF 37R）。七个竖排三和弦以低、中、高音记，音符均为全音符。图中用框标主、用横括线标下属组和属组。采用括号外 C 大调读法时，谱面如下。

| 组 | 图中自左向右的三和弦 | 共同功能音 |
|---|---|---|
| S | II `D3 F3 A3`；IV `F3 A3 C4`；VI `A3 C4 E4` | A3，音级 VI |
| T | I `C4 E4 G4` | 主功能由 I 承担 |
| D | III `E4 G4 B4`；V `G4 B4 D5`；VII `B4 D5 F5` | B4，音级 VII |

括号调号给出 C 和声小调读法，E、A 改降，属组 B4 同在一个小节，首个括号还原号使该音保持 B♮。教材将副三和弦沿共同音归入两个功能组。变调题可同时要求列出实际三和弦音、该组共同音及各和弦与 I 共享的音数。

## 减三和弦的转位与功能强弱

### A-133

印刷 72 页（PDF 38L）。莫扎特 F 大调钢琴奏鸣曲 K. 280 第一乐章，[Allegro assai]，3/4。一个降号的调号下，末两小节的局部和声指向 C 大调。第二小节左手由 D3、F3、B♮3、D4 连续十六分上行，再接 F4，右手同一拍是 B♮4。最低 D 是 B–D–F 的三音，形成 C 大调导音减三和弦第一转位。下一小节的 E3、G3、C4 展开 C 的主三和弦第一转位。辨听时可把琶音先合成和弦，再对比原织体的最低音与根音。

### A-134

印刷 72 页（PDF 38L）。斯卡拉蒂 C 小调第 7 钢琴奏鸣曲，Moderato，普通四拍。第一小节先有 G4 与左手 C4、E♭4，随后在标颤音的 B♮4 下，左手同响 D4 与 F4。这个 D–F–B 的排列明示小调导音减三和弦第一转位。本节正文也把小调 II 的减三和弦列入常用第一转位的情形。可用原谱先让学生把 C–E♭–G 与 B–D–F 改写在同一音区，再指认最低音及声部去向。

### A-135

印刷 73 页（PDF 38R）。七个全音符三和弦的谱面音位与 A-132 一致，主和弦仍放在框内。下属组在谱上从左到右为 II、IV、VI，箭头朝左，表示 VI→IV→II。属组从左到右为 III、V、VII，箭头朝右。对主和弦的共同音数依箭头递减为 2、1、0。正文也列出跳过中间和弦的 VI→II 和 III→VII。生成对比题时可分别听按箭头强化及反向减弱，再逐一数与主和弦共有的音。

## VI 的准备与去向

### A-136а

印刷 74 页（PDF 39L）。莫扎特 C 大调钢琴奏鸣曲 K. 545 第二乐章，Andante，3/4，一个升号，此处以 G 为主音。第二小节第一拍左手为 G3、D4、B3、D4 四个十六分音，第二拍换成 E3、B3、G3、B3，上方同时出现 G5。低音根音 G→E，B、G 仍让两和声相连，形成 I→VI。教材在该例前指出，VI 最常从主功能准备。

### A-136б

印刷 74 页（PDF 39L）。李斯特《旅行岁月》之《威廉·退尔教堂》，Lento，普通四拍。第一小节两半的低音框架由 C2 到 A1，第一组分解和声的 C2、G2、C3、G3 与右手 E、G、C 构成主，第二组左手以 A 音区开始，右手含 C4、E4、A4、C5，构成 VI。其后有升号形成通向 E 的和声变化。前两拍组可直接与 A-136а 比较主到下中音和弦在不同织体中的共同音。

### A-137а

印刷 74 页（PDF 39L）。三个二分和弦对，按女高、女低、男高、低音排列。第一组列采用括号调号的 C 小调读法，后两组用谱面还原后的 C 大调读法。

| 功能 | 四部进行 |
|---|---|
| VI→IV | C5 A♭4 E♭4 A♭3 → C5 A♭4 F4 F3 |
| IV→II | C5 A4 F4 F3 → D5 A4 F4 D3 |
| VI→II | E5 A4 C4 A3 → F5 A4 D4 D3 |

第一、二组有两个共同音，第三组只保留女低 A4。可以按指定共同音数要求学生写出两条下属组强化路线。

### A-137б

印刷 75 页（PDF 39R）。多梅尼科·斯卡拉蒂 C 大调第 4 钢琴奏鸣曲，Allegro，二二拍。左右手在前三个小节开头用纵向和弦点明和声，第三小节进入前后低音 A2→F2，上声部又保持 C5 一带的重复音。这里可从 A、C、E 的 VI 听到 F、A、C 的 IV，和 A-137а 首组的三度根音关系相同。可把每个小节的第一击抽给学生标功能，再回到谱面看同一音型如何跨和声继续。

### A-138

印刷 75 页（PDF 39R）。格里格《精灵之舞》Op. 12 No. 4，Molto allegro e sempre staccato，3/4，一个升号。第一小节前两拍右手齐奏 E4、G4、B4、E5，第三拍换 C4、G4、C5、E5，后一小节首拍回 E 小调原配置。开端左手没有同时起奏的和弦，右手最低声部 E4→C4→E4 支持 I→VI→I。可要求学生保留 G4、E5，比较舒缓的三度关系与属到主的收束力度。

### A-139

印刷 75 页（PDF 39R）。C 和声小调，二分和弦。两组把 VI 直接接到 V，括线「ув. 2」标在女低音。

| 组 | 四部进行 | 谱面问题 |
|---|---|---|
| 左 | C5 A♭4 E♭4 A♭3 → D5 B♮4 G4 G3 | 女低 A♭4→B♮4 增二度 |
| 右 | E♭4 A♭3 C3 A♭2 → G4 B♮3 D3 G2 | 女低 A♭3→B♮3 增二度 |

正文说明从最弱下属直接到属既有功能跨度，在小调里还容易引出增二度。可改写为 VI→IV→V，让学习者逐声部检验增二度是否消失。

## 大调 II 的准备及解决

### A-140

印刷 76 页（PDF 40L）。C 大调三个二分和弦对。女高、女低、男高、低音依次列出。

- IV→II。`A4 F4 C4 F3 → A4 F4 D4 D3`
- VI→II。`C5 E4 A3 A3 → D5 F4 A3 D3`
- VI→II。`A4 E4 C4 A2 → F4 D4 A3 D3`

先比较 IV 和 II 保留 A、F 的和声连接，再比较 VI 到 II 的有共同音与重新分配共同音两种处理。

### A-141

印刷 76 页（PDF 40L）。两个 C 大调 I→II，均为二分和弦。因没有共同音，教材以相向移动的声部数量概括两式。

- 1:3。`C5 E4 G3 C3 → A4 D4 F3 D3`。低音上行，其他三部下行。
- 2:2。`E5 G4 C4 C3 → F5 F4 A3 D3`。低音和主三音所在的女高上行，另两部下行。

迁移题可先给固定女高，在两式中选择能照顾旋律方向及相邻声部距离的配置。

### A-142

印刷 76 页（PDF 40L）。三个 C 大调 II→V→I。各位置时值为二分、二分、四分。

| 组 | 四部进行 |
|---|---|
| 1 | F4 D4 A3 D3 → G4 D4 B3 G2 → E4 C4 G3 C3 |
| 2 | F4 D4 A3 D3 → D4 B3 G3 G3 → E4 C4 G3 C3 |
| 3 | D5 F4 A3 D3 → B4 D4 G3 G3 → C5 E4 G3 C3 |

第一组的虚线连女低 D4，指出 II 与 V 的共同音留在同一声部。第 2、3 组以不同的旋律位置把 D 分配给另一声部，可让学生分别按和声连接与旋律连接实现 II–V。

### A-143

印刷 77 页（PDF 40R）。两个 C 大调 II–K₆₄–V 范型。首个和弦与后续两次上部和弦均用二分。后续两时点中，固定的两条下声部各保持一个全音符。

- `D5 F4 A3 D3 → C5 E4 G3 G3 → B4 D4 G3 G3`。
- `F4 D4 A3 D2 → E4 C4 G3 G2 → D4 B3 G3 G2`。

此处 II 在终止区准备 K₆₄。可指定保持同度或八度的低声部，让学生标出上方的 6–5 与 4–3。

### A-144

印刷 77 页（PDF 40R）。四组 C 大调二分和弦。前后两对均把直接 II–I 和经 V 的走向相邻列出。

| 组 | 四部进行 |
|---|---|
| 1 | D5 F4 A3 D3 → E5 G4 C4 C3 |
| 2 | D5 F4 A3 D3 → B4 D4 G3 G3 → C5 E4 G3 C3 |
| 3 | A4 F4 D4 D3 → C5 G4 E4 C3 |
| 4 | A4 F4 D4 D3 → B4 G4 D4 G3 → C5 G4 E4 C3 |

按正文比较直接以二度根音关系回主和通过 V 的功能方向。两类可限定相同调与起止和弦，用键盘对听。

### A-145

印刷 77 页（PDF 40R）。五个二分和弦对。以 C 大调读出表内音高。第 1、2 与第 5 组可采用括号的 C 小调调号，E、A 改降。第 3、4 组前的取消调号保留 C 大调。

| 组 | 四部进行 | 虚线标出的共同音 |
|---|---|---|
| 1 | A4 E4 C4 A3 → A4 F4 C4 F3 | 女高 A4、男高 C4 |
| 2 | E4 A3 C3 A2 → F4 A3 C3 F2 | 女低 A3、男高 C3 |
| 3 | A4 C4 F3 F3 → A4 D4 F3 D3 | 女高 A4、男高 F3 |
| 4 | F5 A4 C4 F3 → F5 A4 D4 D3 | 女高 F5、女低 A4 |
| 5 | G4 E4 C4 C3 → A4 E4 C4 A2 | 女低 E4、男高 C4 |

前四组分别为 VI–IV 或 IV–II，末组为 I–VI。教材把三度根音关系中留在原声部的两个共同音作为默认写法。可指定两个必须保留的音及声部，要求学习者改变其余声部和根音。

### A-146

印刷 78 页（PDF 41L）。两个 C 大调 VI→II 二分和弦对，四部依女高、女低、男高、低音。

- 和声连接 `C5 E4 A3 A3 → D5 F4 A3 D3`。虚线强调男高 A3 保持原位。
- 旋律连接 `C5 E4 A3 A2 → A4 D4 F3 D3`。A 从男高换到女高，低音上行，其余下行。

根音为四、五度关系时，两种连接均可用。可固定 II 的低音八度，让学生分别写一例并指出共同音的去向。

### A-147

印刷 78 页（PDF 41L）。两组 I→VI→II，三个和弦各为二分，C 大调。

| 原书判断 | 四部进行 |
|---|---|
| 不理想 | G4 E4 C4 C4 → A4 E4 C4 A3 → A4 F4 D4 D3 |
| 较好 | G4 E4 C4 C3 → A4 E4 C4 A2 → F4 D4 A3 D3 |

原书在左组低音 C4→A3→D3 下画线，标出同向下落形成的七度跨度。右组低音 C3→A2→D3 作折返。出题可固定功能及初末低音，让学生修改八度，检查低音线条与上三声部的配置是否共同成立。

### A-148

印刷 78 页（PDF 41L）。四组 C 大调 II–K₆₄–V。II 用二分；K₆₄ 与 V 各二分，若有全音符则该声部保持至 V。

| 谱面 | 四部进行 |
|---|---|
| 左侧反例 | A4 D4 F3 D2 → G4 C4 E3 G2 → G4 B3 D3 G2 |
| 左侧改写 | A4 D4 F3 D2 → G4 E4 C4 G2 → G4 D4 B3 G2 |
| 右侧反例 | F5 A4 D4 D3 → E5 G4 C4 G3 → D5 G4 B3 G3 |
| 右侧改写 | F5 A4 D4 D3 → C5 G4 E4 G3 → B4 G4 D4 G3 |

左侧反例在女高、女低之间出现 D4–A4 到 C4–G4 的平行五度。右侧反例在男高、女低之间出现 D4–A4 到 C4–G4 的平行五度。原图以括线标出左侧改写的男高 F3→C4、右侧改写的女高 F5→C5。可把同一功能与节奏保留，分别修正一组四部写法。

## 三度关系的调性模进

### A-149

印刷 79 页（PDF 41R）。三组全音符堆叠，以低至高记 `C4 E4 G4 → E4 G4 B4 → G4 B4 D5`。依次是 C 大调、E 小调、G 大调的主三和弦。第四组被划去，显示只用原 C 大调七个音的边界。可让学生写出下一组 B–D–F 及引入 F♯ 后的对照，解释何时仍可继续轮换大小调。

### A-150а

印刷 79 页（PDF 41R）。上中音方向的全音符三和弦，以下按低至高记并保留图中音区。

| 调性 | 实际音高 |
|---|---|
| C 大调 | C4 E4 G4 |
| E 小调 | E4 G4 B4 |
| G 大调 | G4 B4 D5 |
| B 小调 | B4 D5 F♯5 |
| D 大调 | D5 F♯5 A5 |
| F♯ 小调 | F♯4 A4 C♯5 |
| A 大调 | A4 C♯5 E5 |
| C♯ 小调 | C♯5 E5 G♯5 |

括线配对 E 小调–G 大调、B 小调–D 大调、F♯ 小调–A 大调，并由 C♯ 小调继续。每到大调，再按其 III 寻找下一小调。可让学生补完 C♯ 小调对应的大调，再从该大调继续上行。

### A-150б

印刷 79 页（PDF 41R）。贝多芬 D 大调第 7 钢琴奏鸣曲第四乐章，[Allegro]，普通四拍。图中前三个相似单元的低声部起音依次为 D3、F♯3、A3，均用三个八分音走出下行声部，右手的伴随动机在相应位置上移。教材把它放在上中音调性图之后。可让学习者只圈三个低音起点，再比较移位前后乐句中保留的节奏和声部轮廓。

### A-151

印刷 79 页（PDF 41R）。下中音方向的全音符三和弦。

- C 大调 `C5 E5 G5` → A 小调 `A4 C5 E5`
- F 大调 `F4 A4 C5` → D 小调 `D4 F4 A4`
- B♭ 大调 `B♭3 D4 F4` → G 小调 `G4 B♭4 D5`
- E♭ 大调 `E♭4 G4 B♭4` → C 小调 `C4 E♭4 G4`

原图将各大调与其关系小调括成一对，在 B♭、E♭、C 小调所在位置标相应降音。C 大调出发的根音音级骨架是 C–A–F–D–B♭–G–E♭–C。出题时可要求逐组写关系小调并标实际改动的音。

## 配和声范例与章末习题

### A-152

印刷 80 页（PDF 42L）。八小节，两个升号，普通四拍。四分音符计 1。

| 声部 | 原谱音高与时值 |
|---|---|
| 女高 | `D5:2 D5:1 D5:1 | C#5:1 E5:1 D5:1 F#5:1 | B4:2 G5:1 D5:1 | D5:2 C#5:2 | D5:1 A4:1 B4:1 B4:1 | A4:1 E4:1 F#4:2 | G4:2 F#4:1 E4:1 | D4:4` |
| 女低 | `F#4:3 G4:1 | E4:1 A4:1 F#4:1 A4:1 | G4:2 B4:1 G4:1 | F#4:2 E4:2 | F#4:1 D4:1 D4:2 | C#4:2 D4:2 | D4:2 D4:1 C#4:1 | D4:4` |
| 男高 | `A3:2 B3:1 B3:1 | A3:1 C#4:1 A3:1 D4:1 | D4:3 B3:1 | A3:4 | A3:1 F#3:1 F#3:1 G3:1 | E3:1 A3:1 A3:2 | B3:2 A3:1 G3:1 | F#3:4` |

### A-153

印刷 80 页（PDF 42L）。钢琴第 3 题。五个二分和弦为给定题面，要求分别当作下属组副三和弦 VI 或 II，用各种方式到主。按女高、女低、男高、低音记。

1. `C5 E4 G3 C3`

### 同页口头与钢琴题

- 口头分析下属组副三和弦。作品为格林卡《鲁斯兰与柳德米拉》第一幕柳德米拉的短咏叹调、格林卡歌曲《Смертный час настал нежданный…》、柴可夫斯基 Op. 54 No. 8《杜鹃》及瓦格纳《帕西法尔》前奏。
- 钢琴第 1 题，从 I 的六种配置演奏。大调 I–VI–IV–V、I–VI–IV–II–V、I–IV–II–V、I–VI–II–V。小调 I–VI–IV–V。
- 钢琴第 2 题，按数字演奏四条。大调 I–V–I–VI–II–V，小调 I–VI–IV–K₆₄–V₇–I，大调 I–II–V–I–VI–IV–V，大调 I–IV–II–V–I–VI–IV–I。
