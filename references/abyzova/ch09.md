# 主题 9　下属组三和弦连接中的三音跳进

主题从印刷 83 页（PDF 43R）开始。谱例 158–166 及章末习题至印刷 89 页（PDF 46R）。四部按女高、女低、男高、低音排列。

### A-158

印刷 84 页（PDF 44L）。C 大调，3–3 标的是两个和弦的三音。每组首先两个二分和弦，其余印为四分。

| 组 | 四部进行 | 女高三音间的运动 |
|---|---|---|
| 1 | C5 A4 E4 A3 → F5 A4 D4 D3 → D5 G4 B3 G3 → E5 G4 C4 C3 | VI→II，C5→F5，上行四度 |
| 2 | C5 E4 A3 A2 → F4 D4 A3 D3 → G4 D4 B3 G2 → E4 C4 G3 C3 | VI→II，C5→F4，下行五度 |
| 3 | F4 D4 A3 D3 → B4 D4 G3 G2 | II→V，F4→B4，上行增四度，原图标不使用 |
| 4 | F5 A4 D4 D3 → B4 G4 D4 G3 → C5 G4 E4 C3 | II→V，F5→B4，下行减五度 |

低位女高的和弦用密集排列，高位用开放排列，三音跳进中共同音留在原声部。末组用下行减五度，经 B4→C5 解决。题面可给 II→V 的两种八度布局，让学生先拼写音程再选教材偏好的走法。

### A-159

印刷 85 页（PDF 44R）。六组二分和弦对。表内先以 C 大调列音高。第 1–2 与第 4–5 组使用括号降号时，E、A 改降。第 3、6 组前的还原调号给出 C 大调。

| 关系 | 四部进行 | 女高三音走向 |
|---|---|---|
| I→VI | E4 C4 G3 C3 → C5 E4 A3 A2 | E4→C5，上行六度 |
| VI→IV | C5 A4 E4 A3 → A5 C5 F4 F3 | C5→A5，上行六度 |
| IV→II | A4 F4 C4 F3 → F5 A4 D4 D3 | A4→F5，上行六度 |
| I→VI | E5 G4 C4 C4 → C5 A4 E4 A3 | E5→C5，下行三度 |
| VI→IV | C5 E4 A3 A2 → A4 F4 C4 F3 | C5→A4，下行三度 |
| IV→II | A4 C4 F3 F2 → F4 D4 A3 D2 | A4→F4，下行三度 |

前后三例可连成一对移调或改排列练习。原图高位用开放、低位用密集。根音三度关系允许上行六度，也允许旋律上仍属平稳进行的下行三度。

### A-160

印刷 85 页（PDF 44R）。三个连用三音跳进的写作示范。前两组按括号外 C 大调读音，使用括号内调号则 E、A 降半音，属三音 B 依谱还原。第三组的三个还原号取消原调号。

| 组 | 四部进行 | 原谱时值顺序 |
|---|---|---|
| 1 | E5 G4 C4 C4 → C5 A4 E4 A3 → A5 C5 F4 F3 → G5 B4 D4 G3 → E5 G4 C4 C4 | 二分、二分、二分、四分、四分 |
| 2 | E4 C4 G3 C3 → C5 E4 A3 A2 → A4 F4 C4 F2 → G4 D4 B3 G2 | 二分、二分、二分、四分 |
| 3 | C5 E4 A3 A3 → A4 F4 C4 F3 → F5 A4 D4 D3 → B4 G4 D4 G3 → C5 G4 E4 C3 | 二分、二分、二分、二分、四分 |

前两组在 I–VI–IV 间按不同次序组合上六度、下三度，第三组扩展到 VI–IV–II–V–I。训练可先固定 VI 与 IV 的女高所在音区，再安排下一对三音与最后的属到主。

## 三度根音关系的特殊连接

### A-161

印刷 86 页（PDF 45L）。六组二分和弦均采用旋律连接，低音向下而上三声部向上。先列 C 大调读法，第 1–5 组可按括号内的三个降号读 C 小调，E、A 改降。第 6 组前取消降号。

| 组 | 四部进行 |
|---|---|
| 1 | G4 C4 E3 C3 → C5 E4 A3 A2 |
| 2 | E5 G4 C4 C4 → A5 C5 E4 A3 |
| 3 | C5 E4 G3 C3 → E5 A4 C4 A2 |
| 4 | E4 C4 G3 C3 → A4 E4 C4 A2 |
| 5 | C5 E4 A3 A2 → F5 A4 C4 F2 |
| 6 | C5 F4 A3 F3 → F5 A4 D4 D3 |

功能依次为四组 I→VI，接一组 VI→IV、一组 IV→II。三声部同时远离原有位置时，仍可保留原排列。原图括线标出的跳进有时主要出现在中声部。教材认为女高较平稳而中声部跳进的写法效果较弱。出题时可给相同的根音关系与同一排列，要求核对三个上方声部各自是否发生跳进。

### A-162

印刷 86 页（PDF 45L）。三个二分和弦对，高音从密集位置的根音起步。前两组可采用括号的 C 小调调号，第 3 组还原为 C 大调。以下列 C 大调。

- I→VI。`C5 G4 E4 C4 → E5 A4 C4 A3`
- VI→IV。`A4 E4 C4 A3 → C5 F4 A3 F3`
- IV→II。`F4 C4 A3 F3 → A4 D4 F3 D3`

女高均上行三度，按本书术语属平稳进行，排列却由密集换成开放。练习可保留出发和弦的女高位置，让学习者找下方三度根音及不必大跳的三条高音。

### A-163

印刷 86 页（PDF 45L）。G 大调，3/4。按谱内小节线分九小节，四分音符计 1。

| 声部 | 音高与时值 |
|---|---|
| 女高 | `B4:2 G4:1 | A4:2 A4:1 | B4:1 E5:1 C5:1 | A4:2 D5:1 | B4:1 G4:1 C5:1 | F#4:1 G4:1 E4:1 | D4:2 B4:1 | A4:2 F#4:1 | G4:3` |
| 女低 | `D4:2 E4:1 | E4:2 F#4:1 | G4:2 A4:1 | F#4:2 F#4:1 | D4:1 E4:1 E4:1 | D4:1 D4:1 C4:1 | B3:2 D4:1 | D4:2 C4:1 | B3:3` |
| 男高 | `G3:2 B3:1 | C4:2 D4:1 | D4:1 C4:1 E4:1 | D4:2 A3:1 | G3:1 B3:1 A3:1 | A3:1 B3:1 G3:1 | G3:3 | F#3:2 A3:1 | G3:3` |
| 低音 | `G3:2 E3:1 | A3:2 D3:1 | G3:1 C3:1 A2:1 | D3:2 D3:1 | G3:1 E3:1 A2:1 | D3:1 G2:1 C3:1 | D3:3 | D2:3 | G2:3` |

第 1 小节女高 B4→G4 虽只有下行三度，图中仍把两音标 3，对应 I→VI。第 3 小节 B4→E5→C5 和第 5–6 小节 B4→G4→C5→F♯4 连用几种三音位置。教材建议先标旋律的跳进，辨认和弦内改排与跨和弦三音，再标密集或开放。可先给女高和两个外声部的功能框架，让学习者复现同一处配置变化。

## 章末习题

印刷 87–89 页（PDF 45R–46R）。钢琴及书面任务均见[逐音题面](ch09-exercises.md)。

- 口头题在格林卡《鲁斯兰与柳德米拉》第五幕拉特米尔与芬恩的二重唱、穆索尔斯基歌曲《Где ты, звездочка》中找出并分析下属组三和弦。
- 钢琴第 1–4 题。大小调分别练上跳和下跳，再按全音向上或向下移调。大调用 I³–VI³、VI³–IV³、IV³–II³–V–I。小调用 I³–VI³、VI³–IV³–V–I。右上角 3 指女高为三音。
- **A-164，钢琴第 5 题。** 七组给定四部模进动机。
- **A-165，钢琴第 6 题。** 两条旋律、三条低音的配和声短句。第 7 题另要求自编含本章三音跳进的乐段，并在多种大小调中演奏。
- **A-166，书面题。** 章末十条给定旋律，要求配和声。自编题可固定女高的跳进方向，保留学生决定下属组的空间。
