# 主题 22 · II 级七和弦及其转位

来源为阿贝佐娃《Гармония》，Музыка，2008。主题始于印刷第 165 页（PDF 84R）。音高按中央 C=C4。

## A-335 · 自然大调、和声大调与小调的 II₇

印刷第 165 页（PDF 84R）。教材用三个原位、密集的全音符和弦对照结构，从低到高如下。

| 调式 | 音高 | 结构 |
|---|---|---|
| C 自然大调 | D4 F4 A4 C5 | 小小七和弦 |
| C 和声大调 | D4 F4 A♭4 C5 | 半减七和弦。A 有临时降号。 |
| c 小调 | D4 F4 A♭4 C5 | 半减七和弦。A♭ 由调号给出。 |

三组都以 D 作根音，七音保持 C，和声大调与小调的五音均为 A♭。可给同主音三种调式，让学生只改动必要音并比较功能保持与音响变化。按紧接的正文，II₆₅、II₄₃、II₂ 的低音依次为 IV、VI、I 级。

## A-336 · II₇ 与 II₆₅ 的排列

印刷第 166 页（PDF 85L）。三个降号。各音都是二分，按 S/A/T/B 记录。

| 原书分类 | S/A/T/B |
|---|---|
| II₇ 密集 | A♭4/F4/C4/D3 |
| II₇ 开放 | C5/F4/A♭3/D3 |
| II₆₅ 密集 | D4/C4/A♭3/F3 |
| II₆₅ 混合 1 | A♭4/D4/C4/F3 |
| II₆₅ 混合 2 | C5/A♭4/D4/F3 |
| II₆₅ 混合 3 | D4/A♭3/C3/F2 |
| II₆₅ 开放 1 | A♭4/C4/D3/F2 |
| II₆₅ 开放 2 | C5/D4/A♭3/F2 |

教材把 II₆₅、II₄₃ 称为常用终止转位，因为低音 IV、VI 均可级进到终止四六的低音 V。以 F3 或 F2 为给定低音出题时，可让学生各写一个含 C 七音的配置，再选延留七音最方便的连接。原位 II₇ 也可进终止四六，此时低音跳进。

## A-337–338 · 从下属组与主组准备

印刷第 166 页（PDF 85L）。三个降号。除 337.4 下两声部用全音符外，均为二分。表内每一位置依 S/A/T/B 顺序列写。

|---|---|---|

| 337.2 | C5/F4/C4/A♭2 | D5/F4/C4/A♭2 |
| 337.3 | C5/A♭4/E♭4/A♭3 | C5/A♭4/D4/F3 |
| 337.4 | D5/F4/A♭3/F3 | C5/D4/A♭3/F3 |
| 338.1 | C5/G4/C4/E♭3 | D5/A♭4/C4/F3 |
| 338.2 | E♭5/G4/C4/C4 | D5/F4/C4/A♭3 |
| 338.3 | E♭4/C4/G3/C3 | F4/D4/A♭3/C3 |

- **337。** 前三组的虚线分别指向保持的女低 C4、男高 C4、女高 C5。末组以女高 D5–C5 引入七音，男高 A♭3、低音 F3 跨整组保留。

## A-339 · II₇ 的六种去向

印刷第 167 页（PDF 85R），三个降号。每组起始均为 F5/A♭4/C4/D3 的二分和弦，随后解决到下表的二分和弦。

| 原书所标结果 | S/A/T/B |
|---|---|
| K₆₄ | E♭5/G4/C4/G3 |
| V 原位 | D5/G4/B♮3/G3 |
| 完整 V₇ | D5/F4/B♮3/G3 |
| 不完整 V₇ | F5/G4/B♮3/G3 |
| V₄₃ | F5/G4/B♮3/D3 |
| I₆ | G5/G4/C4/E♭3 |

附表还列各转位的候选去向。II₆₅ 可进 K₆₄、V、完整或不完整 V₇、V₂，并可下属到主功能。II₄₃ 可进 K₆₄、V、完整或不完整 V₇，或下属到主功能。II₂ 可进 V₆、V₆₅ 或 I。按同一给定 II₇ 编多解题时，可要求分别尝试终止四六、属功能、直接主功能，并点明七音 C 何处保留、何处下行。

## A-340 · 下属到主六的三对正误示范

印刷第 167 页（PDF 85R），三个降号。全部为二分。原书把三对中的前组标「плохо」，圈出不宜声部。后组用 1–5 表示相对主和弦根音和五音的跳进。

| 组 | 评价 | 起始 S/A/T/B | 解决 S/A/T/B |
|---|---|---|---|
| 1 | 不宜 | D4/C4/F3/A♭2 | C4/C4/G3/E♭2 |
| 1 | 改写 | D4/C4/F3/A♭2 | G4/C4/G3/E♭2 |
| 2 | 不宜 | A♭4/C4/D3/F2 | G4/C4/C3/E♭2 |
| 2 | 改写 | A♭4/C4/D3/F2 | G4/C4/G3/E♭2 |
| 3 | 不宜 | D5/A♭4/C4/F3 | C5/G4/C4/E♭3 |
| 3 | 改写 | D5/A♭4/C4/F3 | G5/G4/C4/E♭3 |

第 1 对的相邻上声部由二度进入同音。第 2 对维持 C4 并令 D3 下到 C3，使内声部七度变成八度。第 3 对的女高 D5 下到 C5，和固定的男高 C4 所成九度缩为八度。三个改写均保持其中一个 C，并用实际声部的 G 避免原来的音程归并。适合以原书两版作为纠错题，要求保留低音和固定声部，只换 1 个声部。

## A-341–342 · 终止四六与两种七音进行

印刷第 168 页（PDF 86L），三个降号。各起音为二分。用 S/A/T/B 列写。

| 位置 | 起始和弦 | 解决和弦 |
|---|---|---|
| 341 | D4/C4/F3/A♭2 | G4/C4/E♭3/G2 |
| 342.1 | C5/D4/A♭3/F3 | B♮4/D4/G3/F3 |
| 342.2 | C5/D4/A♭3/F3 | C5/E♭4/G3/C3 |

第 341 号用 II₄₃–K₆₄，女高从 D4 上跳到 G4，原书以 1–5 标出这一声部。第 342 号从同一 II₆₅ 出发。左组进 V₂，七音 C5 和五音 A♭3 同时下行级进。右组进原位 I，女高 C5 保持，男高 A♭3 下到 G3。编对照题时可以锁定首和弦，分别指定属和主为目标，让学生明确 C5 是否保留。

印刷第 168 页（PDF 86L），三个降号。三个位置均为二分，箭头双向。以下横向列三个 S/A/T/B 音组，延音另记。

| 组 | 第 1 位 | 第 2 位 | 第 3 位 | 原书标注与延音 |
|---|---|---|---|---|
| 1 | F5/A♭4/C4/D3 | E♭5/G4/C4/E♭3 | D5/A♭4/C4/F3 | I₆，男高 C4 连三位 |
| 2 | F5/A♭4/C4/D3 | E♭5/A♭4/C4/E♭3 | D5/A♭4/C4/F3 | VI₆₄，女低 A♭4、男高 C4 连三位 |
