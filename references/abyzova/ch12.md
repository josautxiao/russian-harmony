# 主题 12 · 主要三和弦的第一转位与平稳连接

来源为阿贝佐娃《Гармония》，Музыка，2008。主题始于印刷第 103 页下半（PDF 53R）。四部用 S/A/T/B 顺序，以 C4 为中央 C。

## A-193 · 同一个六和弦的十种排列

印刷第 104 页（PDF 54L）。三降号，谱例和弦为 c 小三和弦第一转位。每列都是单独的二分音符和弦，低音均为 E♭3，教材以女高、女低、男高之间的相邻音程区分排列。

| 序号 | 排列 | 四部 | 重复音 |
|---|---|---|---|
| 1 | 密集 | C4/G3/G3/E♭3 | 五音 G |
| 2 | 密集 | C4/C4/G3/E♭3 | 根音 C |
| 3 | 混合 | G4/C4/G3/E♭3 | 五音 G |
| 4 | 混合 | C5/C4/G3/E♭3 | 根音 C |
| 5 | 混合，原书标「不宜」 | C5/G4/G3/E♭3 | 五音 G |
| 6 | 混合 | G4/C4/C4/E♭3 | 根音 C |
| 7 | 混合 | G4/G4/C4/E♭3 | 五音 G |
| 8 | 混合 | C5/G4/C4/E♭3 | 根音 C |
| 9 | 开放 | G5/G4/C4/E♭3 | 五音 G |
| 10 | 开放，原书引塔涅耶夫称「дубовый」 | G5/C5/C4/E♭3 | 根音 C |

第 5、10 种的女低与男高相隔八度。教材认为第 10 种音色格外空，因为上三声部的八度和五度听起来容易融合。部分排列虽有两声部同音，仍应逐声部分开记录。正文提倡重复根音或五音，将主三和弦第一转位的重复三音列为不典型且不宜。用六和弦丰富中段低音线条，也可通过混合排列让声部平稳过渡。

可固定同一个 E♭3，让学生分别写一组重复根音和一组重复五音的六和弦，标相邻上声部音程，再以第 5 和第 10 种作听辨对照。

## A-194–195 · 平稳声部进行与共同音

印刷第 105 页（PDF 54R）。无调号。每个和弦为二分音符，A-194 两组各以全音符收尾。尽量保持同声部的共同音，教材特别要求避免内声部无理由的跳进。

|---|---|---|

| 194 右 | D5/G4/B3/G3 → C5/G4/C4/E3 → B4/G4/D4/G3 | V–I6–V；女高下行，男高上行。排列由开放转密集。 |
| 195.1 | C5/E4/G3/C3 → D5/D4/G3/B2 | I–V6，男高 G3 保持。 |
| 195.2 | B4/G4/D4/G3 → C5/G4/C4/E3 | V–I6，女低 G4 保持。 |
| 195.3 | E5/G4/C4/C4 → F5/F4/C4/A3 | I–IV6，男高 C4 保持。 |
| 195.4 | A4/C4/F3/F2 → G4/C4/G3/E2 | IV–I6，女低 C4 保持。 |
| 195.5 | G4/D4/G3/B2 → E4/C4/G3/C3 | V6–I，男高 G3 保持。 |

## A-196–197 · 二度关系的 IV 与 V

印刷第 105–106 页（PDF 54R–55L）。C 大调。原书两例都把末两组括作「плохо」。每组首和弦为二分音符。196、197 中反例的第二和弦印作四分音符；196 的前三组和 197 的前两组第二和弦为二分音符。

| 组 | 四部 |
|---|---|
| 196.1 | F4/C4/F3/A2 → G4/B3/D3/G2 |
| 196.2 | F4/C4/F3/A2 → D4/B3/G3/G2 |
| 196.3 | C5/F4/C4/A2 → B4/G4/D4/G2 |
| 196.4 | C5/C4/F3/A2 → B4/D4/G3/G2 |
| 196.5 | C4/C4/F3/A2 → D4/B3/G3/G2 |
| 197.1 | C5/F4/A3/F3 → D5/D4/G3/B2 |
| 197.2 | A4/F4/C4/F3 → G4/G4/D4/B2 |
| 197.3 | A4/C4/F3/F3 → G4/D4/G3/B2 |
| 197.4 | C4/A3/F3/F3 → D4/G3/G3/B2 |

- **196，IV6–V。** 第 4 组的女低、男高，第 5 组的女高、男高都从 C4/F3 同向到 D4/G3，形成平行纯五度。原图用弧线圈定形成五度的声部。
- **197，IV–V6。** 低音 F3→B2 向下减五度，两组可用排列都有完整的 IV、V。反例起始处男高同低音为 F3 同度；第 3 组女低、男高，第 4 组女高、男高又形成上述平行五度。
- **出题。** 固定 F3→B2，分别给可用和不可用的 IV 排列，让学生写 V6 并用实际声部说明原书评价。随后将同一验证移到其他大小调。

## A-198–200 · 副三和弦与主要六和弦

| 组 | 四部 | 功能 |
|---|---|---|

| 198 右 | C5/F4/C4/A2 → D5/F4/A3/D3 | C 大调 IV6–ii |
| 199.1 | C5/G4/C4/E♭3 → C5/A♭4/E♭4/A♭3 | c 小调 i6–VI |
| 199.2 | C5/G4/C4/E♭3 → B♭4/G4/E♭4/E♭3 | c 小调 i6–III |

| 199.5 | D5/G4/B♮3/G3 → C5/E♭4/C4/A♭3 → C5/G4/C4/E♭3 | c 小调 V–VI–i6 |
| 199.6 | B4/G4/E4/E3 → C5/G4/C4/E3 | C 大调 iii–I6 |
| 199.7 | D5/F4/A3/D3 → C5/G4/C4/E3 | C 大调 ii–I6 |
| 200.1 | F4/D4/A3/D3 → G4/D4/G3/B2 | C 大调 ii–V6 |
| 200.2 | E5/G4/B3/E3 → D5/G4/D4/B2 | C 大调 iii–V6 |
| 200.3 | A♭4/E♭4/C4/A♭3 → G4/D4/D4/B♮2 | c 小调 VI–V6；低音下行减七度。 |

198 用单个声部的移动展示较弱的 VI 进入 IV6，再举 IV6 进入 ii。199 展示 i6/I6 能准备或承接副三和弦。小调 III 接 V6 会遇到交叉变音，教材此处将自然七级在 III 上、升七级在 V6 低音上的冲突列为限制。

## A-201–202 · V6 的例外去向与六和弦内重排

印刷第 107 页（PDF 55R）。

- **201，C 大调。** E4/C4/G3/C3 → G4/D4/G3/B2 → A4/C4/E3/A2 ｜ E4/C4/G3/C3 → G4/D4/G3/B2 → C5/C4/E3/A2。两组都是二分、二分、全音符。末和弦分别重复根音 A 和三音 C。原文说明在某些旋律下 I–V6–VI 可作例外用法，低音 C3–B2–A2 连续下行。
- **202，c 小调。** 每组只有女高两枚二分音符，其余声部均为全音符。以持续音判断重配前后的和弦。小调属六的低音 B2 在原图括号内标还原。

|---|---|---|---|
| 202.1 | D4 → G4 | D4/G3/B♮2 | V6 |
| 202.2 | C5 → F4 | C4/F3/A♭2 | iv6 |

## A-203 · 配和声示范

印刷第 108 页（PDF 56L）。e 小调，3/4，起拍 1 拍，末节 2 拍。以下四分音符为 1。女高先从属六进入主和弦，随后谱内用六和弦使低音线条更灵活。第 6 个完整小节的女高 B4→B5 发生在同一和弦内，B4 在女低持续。

| 声部 | 原谱 |
|---|---|
| S | `B4:1 \| G4:2 F#4:1 \| E4:2 B4:1 \| C5:1 E4:1 A4:1 \| F#4:2 B4:1 \| G4:1 E5:1 C5:1 \| B4:1 B5:1 A5:1 \| G5:2 F#5:1 \| E5:3 \| C5:2 A4:1 \| B4:2` |
| A | `F#4:1 \| E4:2 D#4:1 \| E4:2 E4:1 \| E4:1 C4:1 E4:1 \| D#4:2 F#4:1 \| E4:1 G4:1 A4:1 \| B4:2 C5:1 \| B4:2 A4:1 \| G4:3 \| A4:2 E4:1 \| G4:2` |
| T | `B3:1 \| B3:2 B3:1 \| G3:2 B3:1 \| A3:3 \| B3:2 B3:1 \| B3:1 C4:1 E4:1 \| E4:2 E4:1 \| E4:2 D#4:1 \| E4:3 \| E4:2 C4:1 \| E4:2` |
| B | `D#3:1 \| E3:2 B2:1 \| C3:2 G2:1 \| A2:2 C3:1 \| B2:2 D#3:1 \| E3:1 C3:1 A2:1 \| G2:2 A2:1 \| B2:3 \| C3:3 \| A2:3 \| E2:2` |

比较第 3 个完整小节两种 iv 写法时，保持男高 A3，听辨低音改为 C3 前后的变化。教材建议在强拍和次强拍优先检查外声部的三度、六度类不完全协和音程，然后检验四部的平行五度、八度及不必要的双跳。

## 章末习题

印刷第 108–110 页（PDF 56L–57L）。

- **口头。** 分析贝多芬第三大提琴奏鸣曲的 Adagio cantabile、柴科夫斯基《春天》Op. 54 No. 3、门德尔松 A 大调第 4 首《无词歌》，作品顺序按教材。
- **钢琴 1–2。** 从主和弦六种位置弹两类平稳连接 I–V6–I 和 I–IV6–I，对每种起始位置找六和弦的两种配置。
- **钢琴 3–4。** 从 IV 原位的六种位置弹 IV–V6，再从 I 原位的六种位置弹 I–IV6–V。
- **钢琴 5。** 第一和弦从六种位置起弹。原书九组依次为 I–I6–IV–IV6–V，I–V6–V–VI–IV6–I，I–IV6–V–V6–I，I–VI–I6–IV–K–V，大调 I–II–V6–I–IV6–K–V，小调 I–III–IV–V6–I，V–V6–I–IV–V，V–VI–IV6–I–I6–V，I³–V6¹–VI–III–IV–I。上标标旋律中的和弦音，K 为终止四六。
- **钢琴 6。** A-204 的动机按近关系调、全音或上、下中音关系选择合适的模进距离。第 2 组指定全音。
- **钢琴 7。** 依四种功能表弹完整乐段，见下。
- **钢琴 8、10。** A-205 为钢琴配和声题，A-206 为给定开头续成乐段。
- **钢琴 9。** 写含主要六和弦的乐段，在不同大、小调中弹奏。
- **书面 1–2。** A-207 给两条外声部，A-208 给七条旋律和三条低音。
