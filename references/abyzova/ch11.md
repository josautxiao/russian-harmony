# 主题 11 · III 级三和弦

来源为阿贝佐娃《Гармония》，Музыка，2008。主题始于印刷第 97 页（PDF 50R）。下列四部用 S/A/T/B 顺序，以 C4 为中央 C。竖线分开原谱中用双线隔开的示范。没有拍号的示范按和弦先后记录，原书的「3」标和弦三音位置。

## A-180 · 自然小调上方音列下行

第 97–98 页（50R–51L）。

- **180а，c 小调**：C5/G4/E♭4/C3 → B♭4/G4/E♭4/E♭3 → A♭4/F4/C4/F3 → G4/E♭4/C4/C3。i–III–iv–i。开头两和弦保持 G4 和 E♭4，女高唱 C–B♭–A♭–G，B♭是自然七级。
- **180б，柴科夫斯基《第四交响曲》第三乐章**：Allegro，2/4，一降号。印刷第 97 页（PDF 50R）。前两完整小节的八分低音为 F2–A2–D3–F3｜D3–C3–A2–F2，对应上谱高线 F4–E4–D4–C4｜D4–E4–F4–A4。首响实音 F2/A3/C4/F4 立足 F 大三和弦，第三个八分 D3/F3/A3/D4 转成 d 小三和弦。第二小节首响仍有 D3 与上谱 D4/A3/F3，末位以 F2、C4、F4、A4 回到 F。接下来连续两小节在后半以 F2→D2 配上层八分 C5→D5，A4、F4 同时保留，再次使 F 大三和弦变成 d 小三和弦。F 可作为 d 小调的 III 来听。课堂可并排听前两小节和重复的后半拍，比较同一组自然音在两个三和弦之间的支点变化。
- **180в，c 小调，两种 i–III–i**：E♭5/G4/C4/C3 → G4/E♭4/B♭3/E♭3 → E♭5/G4/C4/C3 ｜ E♭4/C4/G3/C3 → G4/B♭3/E♭3/E♭3 → E♭4/C4/G3/C3。女高在 i 与 III 的三音 E♭、G 间跳进，密集和开放排列交替。
- **180г，c 小调**：C5/G4/E♭4/C4 → C5/A♭4/E♭4/A♭3 → B♭4/G4/E♭4/E♭3 → A♭4/F4/C4/F3 → G4/E♭4/C4/C3。i–VI–III–iv–i。VI–III 处 E♭4 留在男高，上两声部下行。

## A-181–182 · VI 准备 III

第 98 页（51L）。VI→III 的四、五度关系可形成 III 调上的 IV–I 或 VI 调上的 I–V 的听觉暗示，结合前后和弦判断。正文另说明 II→III 只能作旋律连接。

| 谱例 | 四部 |
|---|---|
| 181 左，VI–III–iv–V | A♭4/E♭4/C4/A♭3 → G4/E♭4/B♭3/E♭3 → F4/C4/A♭3/F3 → D4/B♮3/G3/G3 |
| 181 右，VI–III–iv–V | C5/E♭4/A♭3/A♭3 → E♭5/G4/B♭3/E♭3 → C5/F4/A♭3/F3 → B♮4/D4/G3/G3 |
| 182 左，VI–III–iv–i | C5/A♭4/E♭4/A♭3 → G5/B♭4/E♭4/E♭3 → F5/A♭4/C4/F3 → E♭5/G4/C4/C3 |
| 182 右，VI–III–V–i | C5/E♭4/A♭3/A♭2 → G4/E♭4/B♭3/E♭3 → G4/D4/B♮3/G2 → E♭4/C4/G3/C3 |

181 左边保持 VI 与 III 的共同音，右边上三声部移动。182 两组女高由 VI 三音 C 跳向 III 三音 G，分别上行五度和下行四度。182 右边自然七级 B♭ 到升七级 B♮留在男高。

## A-183–185 · III 转向 i、IV 或 VI

第 99–100 页（51R–52L）。

- **183а**：G4/E4/C4/C4 → A4/E4/C4/A3 → B4/G4/E4/E3 → C5/G4/E4/C3。C 大调 I–VI–III–I，末尾 G4 与 E4 保持，B4 上行到 C5。教材将这种柔和的直接解决与浪漫派和俄罗斯学派联系。
- **183б**：拉赫玛尼诺夫《b 小调前奏曲》Op. 32 No. 10，Lento。印刷第 99 页（PDF 51R）。引谱三连音弱起后，第一完整小节以高谱 F♯5/D5/B4、低谱 F♯4/D4/B3 的持音确立 i。第三完整小节后半出现 D5/A4/F♯4（上谱）和 D4/A3/F♯3（下谱）的延留层，是 D 大三和弦。其后另奏的下谱短音包含 D2、A2、D3，补出 III 根音。下一个小节上谱的持音回到 D5/B4/F♯4，低谱稍后以 B1、B2 加强 i。练习可比较高谱的 D、F♯ 两个共同音和 A→B，另用迟到的低音标出 III 与 i 的转换。
- **184**：c 小调，六种 III–iv，低音均 E♭3→F3，上三声部皆向下到最近的和弦音。各组按同样顺序可作移调练习。

| A-184 | III | iv |
|---|---|---|
| 1 | E♭4/B♭3/G3/E♭3 | C4/A♭3/F3/F3 |
| 2 | G4/E♭4/B♭3/E♭3 | F4/C4/A♭3/F3 |
| 3 | B♭4/G4/E♭4/E♭3 | A♭4/F4/C4/F3 |
| 4 | E♭5/G4/B♭3/E♭3 | C5/F4/A♭3/F3 |
| 5 | G5/B♭4/E♭4/E♭3 | F5/A♭4/C4/F3 |
| 6 | B♭4/E♭4/G3/E♭3 | A♭4/C4/F3/F3 |

- **185а**：G5/B♭4/E♭4/E♭3 → C5/A♭4/E♭4/A♭3 → E♭5/G4/C4/C3 ｜ E♭5/G4/C4/C3 → G4/E♭4/B♭3/E♭3 → C5/E♭4/A♭3/A♭2 → A♭4/F4/C4/F3 → G4/E♭4/C4/C3。III–VI 可作和声连接，也可在女高用带「3」的 G→C 三音跳进。右段 i–III–VI 连续作三音跳进。
- **185б**：柴科夫斯基《第四交响曲》第三乐章，2/4。印刷第 100 页（PDF 52L）。教材标题写 Allegro，总谱对应第 170 小节 Tempo I 的铜管独立段，见总谱 PDF 第 84 页。凭前三小节每节两次十六分短奏、第四小节改为四次短奏，以及低音长号 D♭3–A♭2｜B♭2–F2｜B♭2–A♭2｜D♭3–A♭2–D♭3–A♭2 可定位。第 172 小节第二次短奏构成 A♭–C–E♭，第 173 小节首次短奏构成 D♭–F–A♭。按本章的小调音级口径，这两次相邻短奏可读成 f 小调的 III–VI。练习时可单取第 172–173 小节的接缝，将圆号、小号的 F 调记谱转换成实音后和长号分开核读。 [《第四交响曲》总谱第 84 页](https://upload.wikimedia.org/wikipedia/commons/4/48/Tchaikovsky_4th_Symphony.pdf#page=84)

## A-186–188 · III→V 与交叉变音

第 100–101 页（52L–52R）。大调可保共同音，也可使用三音跳进。自然小调 III 的自然七级与 V 的升七级留在原声部作半音移动。谱例 187 的后两组被原书括号标作「плохо」。

|---|---|

| 186.2 | E5/G4/B3/E3 → D5/G4/B3/G3 → D5/F4/B3/G3 → C5/E4/C4/C3 |
| 186.3 | G4/E4/B3/E3 → B4/D4/G3/G3，女高三音跳进 |
| 186.4 | G5/B4/E4/E3 → B4/G4/D4/G3，女高三音跳进 |

| 187.3 | G5/B♭4/E♭4/E♭3 → B♮4/G4/D4/G3，自然七级在女低，升七级转入女高 |

## 章末习题

印刷第 101–103 页（PDF 52R–53R）。

- **口头。** 找出 III 的用法并说明上下文。原书指定格林卡《鲁斯兰与柳德米拉》第五幕终曲、排练号 26，穆索尔斯基《图画展览会》〈勇士之门〉，柴科夫斯基合唱《Соловушка》，肖邦 c 小调夜曲 Op. 48 No. 1 中段 C 大调开头乐段。
- **钢琴 1。** 大调和自然小调中，从起始和弦的六种位置起弹 I–III–IV–V、I–VI–III–IV–I、I–III–V–I、VI–III–IV–I。
- **钢琴 2。** I³–III³–VI³–I³ 从密集和开放两种排列起弹，上标 3 对应旋律的和弦三音。
- **钢琴 3。** 把给定大三和弦或小三和弦作为 III，以几种不同连接回到主和弦。
- **钢琴 4。** 按原书大、小调要求移调弹奏：大调 I–III–VI–II–V–I，小调 I–III–IV–V–VI–IV–I，大调 I–II–V–VI–III–V–I，小调 V–VI–III–IV–K–V7–I，大调 V–VI–II–III–VI–IV–K–V。K 为终止四六。
- **钢琴 5–6。** 模进 A-190 的两组动机，给 A-191 的三条外声部配和声。逐音材料见下。
- **钢琴 7。** 写并在不同大小调弹奏使用 III–VI、III–IV 或 III–V 的乐段。
- **书面。** 给 A-192 六条旋律和一条低音配和声。原谱印在谱音上方的叉号表示非和弦音。题干说明括号里的叉号允许按和弦音理解。
