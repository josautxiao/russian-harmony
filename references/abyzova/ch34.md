# 阿贝佐娃主题 34 · 向一级关系调转调

《Гармония》主题 34（Модуляция в тональности I степени родства），印刷第 270–297 页。教材用新调的终止强度区分暂时离调与转调，先比较经离调、经共同和弦的两种渐进方式，再按关系调方向展开。以下音组按女高、女低、男高、低音（S/A/T/B），单一低音持续时另注明。

## A-560 · 贝多芬第 2 钢琴奏鸣曲第三乐章，经离调查明新中心

印刷第 271 页（PDF 137R），Allegretto，3/4，无调号。作品标题的 A-dur 指整首奏鸣曲。教材引谱弱起 E4，开头上谱出现 C5–B4–A4，下谱可辨 A3–E4–B3–E4–C4–E4，先建立 a 小调色彩。前两小节的短型复现后，较长连线跨过和声变化。后段下谱见 D♯4、G♯3，上谱在一组升号后的下行音型中到 E4，最后一小节露出的下谱最低层落到 E2。

可把上方的短句复现和长弧分开标记，沿后段实际出现的升音与低音 E 追查转向，另在乐曲后续读足终止时值再判定结束重音。

## A-561 · 贝多芬第 7 钢琴奏鸣曲第一乐章，经共同和弦转调

印刷第 271–272 页（PDF 137R–138L），Presto，两升，谱面采用带竖线的 C 拍号。作品标题的 D-dur 指整首奏鸣曲。引谱两行，前行的 B–D–F♯ 分解骨架与 F♯ 低层上的 A♯，确立片段起初的 b 小调方向。换页后的第二个完整小节，下谱第二半以 D3–F♯3–B3–F♯3 分解，b 小调 i₆ 可重释为 f♯ 小调 iv₆。

下一小节下谱从 C♯3 分解出 F♯、A，再在同一低音附近写 E♯ 和 G♯，把新调终止四六导向属功能。末小节下谱 F♯2–A2–C♯3–F♯3，随后再击 F♯2，形成 f♯ 小调的确认。可要求学生先圈出不再保留原调位置的 E♯，再向前回找可以双重分析的 B 小三和弦第一转位。

## A-562 · 同一开头的留调与转调

印刷第 272 页（PDF 138L），三降。共同开头为 E♭4/C4/G3/C3 → E♮4/C4/G3/B♭2 → F4/C4/F3/A♭2。两箭头引出两份续写。表中保留各自的共同音组、改变方向的音组与终止。两份示例的第三组低音均为全音，持续覆盖第四组。

| 位置 | 上方留在 c 小调 | 下方转入 E♭ 大调 |
|---|---|---|
| 共同位置 | F4/C4/F3/A♭2 | F4/C4/F3/A♭2，标「共同」 |
| 下一组 | F♯4/C4/E♭3/A♭2 | F♯4/C4/E♭3/A♮2，标「转调」 |
| 终止四六 | G4/C4/E♭3/G2 | G4/B♭3/E♭3/B♭2 |
| 属功能 | B♮4/D4/F3/G2 | D4/B♭3/A♭3/B♭2 |
| 末全音组 | C5/C4/E♭3/C2 | E♭4/B♭3/G3/E♭2 |

两条续写中的 F–F♯–G 相同，A♭ 或 A♮ 的低音却导向不同终止低音。下方的 F♯ 按谱保留，与 A、C、E♭ 组合在音响上也可按 A 减七的等音拼写理解。适合给同一开头出两份续写题，再对照第一个不同的低音与最终主音。

## A-563 · 以新调下属功能作共同和弦

印刷第 272 页（PDF 138L），无调号。教材在第三组标「共同」并注明 I＝IV，下一组标「转调」。终止四六与属七共享持续的 D3。

| 位置 | S/A/T/B |
|---|---|
| 1–2 | C5/E4/G3/C3 → D5/F4/A♭3/B♭2 |
| 共同 | E5/E4/G3/C3 |
| 转调 | A4/E4/G3/C♯3 |
| K₆₄ | B4/D4/G3/D3 |
| V₇ | F♯4/C4/A3/D3 |
| I | G4/B3/G3/G2 |

C 大三和弦在 G 大调承接下属功能，带 C♯ 的音组明确指向 D，最后用终止四六、属七与 G 主和弦巩固。可让学生先改共同和弦的排列，再维持相同的终止低音和 F♯ 的目标。

## A-564 · C 大调和 G 大调的共同三和弦

印刷第 273 页（PDF 138R）。双高音谱示意用虚线连接两个调中组成相同的三和弦。谱内叉去的音组保留为排除标记。

| 音级关系 | 共同音组 |
|---|---|
| C 大调 I＝G 大调 IV | C–E–G |
| C 大调 III＝G 大调 VI | E–G–B |
| C 大调 V＝G 大调 I | G–B–D |
| C 大调 VI＝G 大调 II | A–C–E |

正文优先取原调 I、III、VI 作枢纽，以推迟新调主和弦的出现。G–B–D 仍显示为共同三和弦，教学写作中留到终止时再用。可先按两调分别拼出全套三和弦并交叉核对 F 与 F♯ 的差异，再验证四条虚线。

## A-565 · 从 C 大调到 G 大调，经 I＝IV

印刷第 274 页（PDF 139L），无调号。开始到转调前为二分音组，末组为全音。按谱面阶段录为 S/A/T/B。

| 阶段 | 音组 |
|---|---|
| 原调 | E4/C4/G3/C3 → F4/D4/A3/C3 → G4/D4/G3/B2 |
| 共同 | E4/C4/G3/C3 |
| 转调 | E4/A♯3/G3/C♯3 |
| 新调终止 | D4/B3/G3/D3 → F♯4/C4/A3/D2 → G4/B3/G3/G2 |

从共同和弦保留 E4、G3，低音由 C 升到 C♯，男低继而进入 D。和声题可固定 I＝IV，让学生写变音下属及 K₆₄–V₇–I，再对照教材最后的 D3 与 D2 两个低音位置。

## A-566 · 从 C 大调到 G 大调，经 VI₆＝II₆

印刷第 274 页（PDF 139L），无调号，末组全音，其余为二分音组。按 S/A/T/B。

| 阶段 | 音组 |
|---|---|
| 原调 | E4/C4/G3/C3 → F4/B3/G3/D3 → G4/C4/G3/E3 |
| 指向过渡 | G♯4/B3/F3/D3 |
| 共同 | A4/C4/E3/C3 |
| 转调 | G4/A♯3/E3/C♯3 |
| 新调终止 | G4/B3/D3/D3 → F♯4/C4/D3/D2 → G4/B3/D3/G2 |

A 小三和弦第一转位先承接含 G♯ 的音组，再在 G 大调充当 II₆。教材 K₆₄ 的下谱 D3 两部并读。可要求学生用一处短时倾向把 VI₆ 放稳，随后写清它在新调中的音级和进入 K₆₄ 的声部连接。

## A-567 · 从 C 大调到 G 大调，经 III＝VI

印刷第 274 页（PDF 139L），无调号，末组全音，其余为二分音组。按 S/A/T/B。

| 阶段 | 音组 |
|---|---|
| 原调 | G4/C4/G3/C3 → F4/C4/A3/D3 → D4/B3/G3/G3 |
| 指向过渡 | D♯4/B3/A3/F♯3 |
| 共同 | E4/B3/G3/E3 |
| 转调 | G4/C♯4/G3/E3 |
| 新调终止 | B4/D4/G3/D3 → A4/C♮4/F♯3/D3 → G4/B3/G3/G2 |

第三组下谱 G3 两部并读。含 D♯ 的 B 属七第一转位引出 E 小三和弦。重释为 G 大调 VI 后，C♯ 引向新调属低音 D，随后女低 C♯–D–C♮–B 保留半音拼写。可给学生分别用 III＝VI 与 I＝IV 写同一终止，比较共同和弦之前必须怎样准备。

## A-568 · c 小调与 g 小调的共同三和弦

印刷第 275 页（PDF 139R）。上下两行均用高音谱，上方三降、下方两降。虚线连出自然小调三和弦中的四个相同音组，叉号定位其余被排除的位置。

| 原调 c 小调 | 新调 g 小调 | 组成 |
|---|---|---|
| I | IV | C–E♭–G |
| III | VI | E♭–G–B♭ |
| 自然 V | I | G–B♭–D |
| 自然 VII | III | B♭–D–F |

教材把目标主和弦 G–B♭–D 留在终止，转调方案取 C、E♭ 或 B♭ 为共同和弦。可先让学生在两行各标出 G–B♭–D，再说明它在原调的自然属级和在目标调的主功能怎样不同。

## A-569 · 从 c 小调到 g 小调，经 I₆＝IV₆

印刷第 275 页（PDF 139R），三降。末组为全音，前六组为二分。按 S/A/T/B。

| 阶段 | 音组 |
|---|---|
| 原调 | E♭4/C4/G3/C3 → F4/B♮3/G3/D3 |
| 共同 | G4/C4/G3/E♭3 |
| 转调 | A♮4/C♯4/G3/E♭3 |
| 新调终止 | B♭4/D4/G3/D3 → D5/C4/F♯3/D2 → G4/B♭3/G3/G2 |

C 小三和弦第一转位在新调作 IV₆。下一组保持 E♭ 与 G，加入 A♮、C♯ 构成增六音响，E♭ 低音下行至 D，C♯ 上行至 D。可给定共同和弦的低音，要求学生分别核对两个半音在实际声部的位置。

## A-570 · 从 c 小调到 g 小调，经 III＝VI

印刷第 275 页（PDF 139R），三降。末组为全音。第 7、8 音组的低音 D3 为同一个全音，其他可见音组按二分。按 S/A/T/B。

| 阶段 | 音组 |
|---|---|
| 原调 | E♭5/E♭4/G3/C3 → D5/F4/A♭3/B♮2 → C5/E♭4/G3/C3 |
| 共同和弦的准备 | B♭4/F4/(B♭3)/D3 |
| 共同 | G4/E♭4/B♭3/E♭3 |
| 转调 | C5/G4/A♮3/E♭3 |
| 新调终止 | D5/G4/B♭3/D3 → F♯5/A♮4/C4/D3 → G5/G4/B♭3/G2 |

括号内 B♭3 的降号在谱面带括号。B♭ 大三和弦第一转位引出 E♭ 大三和弦。E♭ 在 g 小调改作 VI，并在低音保持时由 A♮ 引入小调 II₄₃，随后接到 D 低音的终止。练习可让学生先把原调 III 准备清楚，再比较用共同低音或换低音进入新调下属功能。

## A-571 · 从 c 小调到 g 小调，经自然 VII＝III

印刷第 276 页（PDF 140L），三降。按 S/A/T/B。共同和弦位置的下谱两个全音各持续两组上谱二分音，末组也为全音。

| 阶段 | 音组 |
|---|---|
| 原调和顺序准备 | G4/C4/G3/E♭3 → F4/D4/G3/B♮2 → E♭4/C4/G3/C3 → E♭4/C4/F3/A♮2 |
| 共同 | D4/B♭3/F3/B♭2 → B♭4/D4/F3/B♭2 |
| 转调 | A♮4/C4/E♭3/C3 |
| 新调终止 | G4/B♭3/D3/D3 → F♯4/C4/D3/D3 → G4/B♭3/D3/G2 |

A♮2 上的 F 属七引出 B♭ 大三和弦。两个共同位置保留下谱，再把 B♭ 重释为 g 小调 III。教材列出从 III 接 IV、II₆ 或 II₇–II₆₅，再经变音下属进入终止的路线。此例实际用 A 半减七第一转位进入 D 低音，两个 D3 位置上下符干共用下谱音头。出题可先固定共同和弦，再选一条不同的下属路线。

## A-572 · 从 c 小调到大调属方向的和声关系调

印刷第 276 页（PDF 140L），三降。按 S/A/T/B。终止中 D3 的全音低音覆盖两组上方二分音，末组为全音。

| 阶段 | 音组 |
|---|---|
| 原调 | E♭4/C4/G3/C3 → G4/B♮3/F3/D3 |
| 共同 | E♭5/C4/G3/E♭3 |
| 转调 | B♮4/C♯4/G3/E♭3 |
| 新调终止 | B4/D4/G3/D3 → A♮4/C4/F♯3/D3 → G4/B♮3/G3/G2 |

c 小调的主和弦重释为 G 和声大调的 iv。转调组保留 E♭ 低音和 G3，引入 C♯ 与 B♮，随后 C♯→D、E♭→D。可与第 569 号对照出题，让学生按目标是 G 大调还是 g 小调决定终止四六与末和弦的三音。

## 主题 34 · 向 V 级调转调的口头题

印刷第 276 页。教材要求分析莫扎特 C 大调钢琴奏鸣曲 K. 330 第二乐章，舒曼《童年情景》Op. 15 中的《梦幻曲》与《幻想小品》Op. 12 中的《黄昏》，普罗科菲耶夫《儿童音乐》Op. 65 中的《黄昏》，勃拉姆斯 d 小调随想曲 Op. 116 No. 7，以及拉赫玛尼诺夫浪漫曲《丁香》。每项可要求给出原调、共同和弦或离调入口、目标调及确认它的终止式。

## A-573 · 钢琴题，向 V 级调续弹两组开头

印刷第 276–277 页（PDF 140L–140R）。钢琴题 1 要求用可选共同三和弦或六和弦弹简短转调，包括原调展示、共同和弦、转调和弦与新调终止。钢琴题 2 要求分别练习大调到大调、小调到小调及小调到和声关系大调的完整乐段。第 3 题给出两个续弹开头。q、e、h 分别为四分、八分、二分，前缀 d 为附点，r 为休止，~ 为延音。

| 组别 | S | A | T | B |
|---|---|---|---|---|
| 1，一升，3/4，第 1 小节 | B4q E5q C5q | G4dh | B3h A♯3q | E3dh |
| 1，第 2 小节的给定部分 | B4h | F♯4h | B3h | D♯3h |
| 2，三降，3/4，弱起 | E♭4e | re | 共用下谱八分休止 | re |
| 2，第 1 小节 | G4dq E♭4e G4e F4e | E♭4h D4q~ | A♮3h B♭3q | C♭3h B♭2e A♭2e |
| 2，第 2 小节的给定部分 | B♭4h | D4q E♭4q | B♭3h | G2h |

第一组从 e 小调色彩转向含 D♯ 的 B 和弦。另一组在第一个完整小节写 A♮3，同时低音 C♭–B♭–A♭–G，女低 D4 延续到下一小节。两组末小节均只提供头两拍供续写。

## A-574 · 向 V 级调转调的书面题

印刷第 277–278 页（PDF 140R–141L）。题目要求为五条旋律与一条低音配和声，取向为属级调。q、e、h、w 分别为四分、八分、二分、全音，前缀 d 为附点，| 分小节，「×」为教材题目提示。

### 1 · 高音，五降，3/2

```text
A♭4q D♭5q E♭5h F5q E♭5q |
D♭5h B♭4h A♭4h | G♭4h F4q G♭4q D♭5q D♭4q |
F4h E♭4h A♭4h | A♭4h G♮4q A♭4q B♭4h |
C5h B♮4q(×) C5q D♭5q B♭4q |
C5h E♭5h F5q E♭5q | A♭4w A♮4h |
B♭4q C5q D♭5h G♮4h | A♭4dw
```

经用户人工确认，末音 A♭4 带附点，为 3/2 小节里的附点全音。可让学生分别圈出 G–A♭ 和 B♮–C，说明它们在转调准备与目标终止中的位置。

### 2 · 高音，两升，3/4

```text
B4q（弱起） |
D5q D5q D5q | D5q C♯5q D5q | F♯4q F♯4q F♯4q |
F♯4q G4q G♯4q | A4q E5q F♯5q |
D5q A4q B4q | C♯5q A4q G♯4q | F♯4h
```

末尾 G♯–F♯ 与中间 G♯–A 的走向不同，可要求给出两处不同的低音与功能。

### 3 · 高音，两降，C

```text
B♭4dq A4e B♭4q C5q |
A4q G4e F4e F5q E♭5e D5e |
E♭5q D5e C5e D5q G♯4q | A4q A4q A4q A4q |
D5q C5e B♭4e A4q G4q |
F4q A4e C5e B♭4q F♯4e A4e |
G4q G♯4q A4q C5q | F5w |
E♮5q(括注×) D5q C5q D5e C5e | F4w
```

第 8 小节先到高 F 全音。下一小节 E♮ 上方有括注叉号，可要求标出该音参与的实际和弦，再解释从高 F 到低 F 的句尾扩展。

### 4 · 高音，四升，6/8

```text
G♯4q A4e F𝄪4q G♯4e |
E4q F♯4e D♯4e E4e F♯4e |
E4q E4e C♯5q B4e |
E5e C♯5e D♯5e B♯4dq |
C♯5q G♯4e B4e(×) A4e F♯4e |
G♯4q D♯4e F♯4q E4e |
D♯4q G♯4e A♯4e F♯5e(×) E5e |
E5dq C♯5q B4e |
B4q D♯4e A♯4e B4e D♯4e | G♯4dh
```

第一小节 F 的重升写在音符前，第 5、7 小节的叉号写在上方。可先分析导音及其解决，再说明教材把哪两个位置交给学生自行选合适的和声。

### 5 · 高音，三升，C

```text
A4q C♯5e A4e F♯4q F♮4q |
E4h F♯4q G♯4q |
A♮4q C♯5e A4e B4q E5q |
D5dq C♯5e B4q A4q | A4h G♯4h |
A4q C♯5e A4e G♯4q D♯5q |
E5h F♯5q G♯5q | D♯5h E5q C♯5q |
B4dq G♯4e G♯4q F♯4q | E4w
```

保留两处 D♯ 和第一小节 F 的还原，第三小节首 A 前印有还原号，记作 A♮4。可要求把上行 D♯–E 与末句下行 G♯–F♯–E 的和声目标分开标注。

### 6 · 低音，一升，C

```text
E3h D3q C3q | B2h A♯2q A♮2q |
G2q G♯2q A2q C3q | D3w ‖
A3h G3q G♯3q | E3q D3q C3q E3q |
F♯3h F♯2h | B2w
```

## A-575 · C 大调和 e 小调的共同三和弦

| 扩充和完全终止 | E♭4/B♭3/G3/G2 → C♯4/A3/G3/A2 → D4/A3/F3/D3 |

C 大三和弦重释为 d 小调自然 VII 后，低线 C–B♭–A 带出弗里吉亚式下行。A 属七先去 B♭，再由 G 上含 E♭ 的音组转回属音。可让学生比较两次 C♯→D 的高层进行与两次实际低音的不同去向。

## A-618 · C 大调转 d 小调，经 IV＝III

印刷第 295 页（PDF 149R），无调号。末组全音，倒数第三组下谱 A3 依上下符干共读。按 S/A/T/B。

| 阶段 | 音组 |
|---|---|
| 原调与准备 | E5/G4/C4/C3 → F5/G4/B3/D3 → G5/G4/C4/E3 → G5/B♭4/C4/E3 |
| 共同 | F5/A4/C4/F3 |
| 转调 | E5/G4/B♭3/G3 |
| 新调终止 | D5/F4/A3/A3 → C♯5/G4/A3/A2 → D5/F4/A3/D3 |

C 属七第一转位先强调 F 大三和弦，再把 F 改作 d 小调 III。转调音组 E–G–B♭ 在低音 G 上构成 II₆，与终止四六连接。可让学生先写原调内的 F，再使用同一旋律，把新调终止改成带扩充的版本。

## A-619 · C 大调转 d 小调，经 VI＝自然 V

印刷第 296 页（PDF 150L），无调号。按 S/A/T/B。末组全音，终止四六和属七共用低音 A3 全音，其余二分。首组低谱 C4 由两个符干共读。

| 阶段 | 音组 |
|---|---|
| 原调与准备 | E5/G4/C4/C4 → D5/G♯4/E4/B3 |
| 共同 | C5/A4/E4/A3 |
| 新调的属七与阻碍 | C♯5/G4/E4/A3 → D5/F4/D4/B♭3 |
| 新调的终止 | B♭4/E4/D4/G3 → A4/F4/D4/A3 → E5/G4/C♯4/A3 → D5/F4/D4/D3 |

A 小三和弦在 C 中是 VI，在 d 中是自然 V。先由 E 属七把 A 小三和弦准备出来，再以 C♯ 将其改写为 d 的属七。教材说明原调 VI 也可由原调内的阻碍进行引入。可给出同一个终止，要求写出两种共同和弦的准备方式，比较何处首次听到 d 的导音。

### 向 II 级调转调的钢琴题

印刷第 296 页（PDF 150L）。

1. 给定任一大调，分别经每个可用的共同三和弦弹向 II 级调的短转调框架，暂不组织节奏。
2. 写一个由大调转入其 II 级调的乐段，在多种调性中练熟。
3. 根据 A-620 的两组开头续弹乐段，终止于原大调的 II 级调。

## A-620 · 向 II 级调续弹的两组开头

印刷第 296 页（PDF 150L）。按 S/A/T/B，q、e、h 分别为四分、八分、二分。第二组末小节只给两拍。

| 片段 | S | A | T | B |
|---|---|---|---|---|
| 1，三升，C，第 1 小节 | A4h B4q D5q | E4h E4h | C♯4h B3h | A3h G♯3h |
| 1，第 2 小节 | C♯5q B4e A4e G♯4h | E4h E4h | A3h B3h | A3h E3h |
| 2，两降，3/4，第 1 小节 | F4q D5q C5q | D4q F4q G♭4q | B♭3h A3q | B♭2h E♭3q |
| 2，第 2 小节给定部分 | F5q B♭4q | F4h | A3q B♭3q | D3h |

第一组保留第二小节起点男高与低音 A3 的重合。第二组保留女低 G♭4，随后低音转入 D3。续写时先按原调确定目标，再检查终止中新调的导音与主音处在何声部。

## A-621 · 向 II 级调转调的四条书面旋律

印刷第 296–297 页（PDF 150L–150R），第 4 条在后页页首。q、e、h、w 分别为四分、八分、二分、全音，dq 为附点四分。

### 1 · 三升，6/8

```text
E5q C♯5e C♯5q B4e | A4e G♯4e F♯4e E4q A4e |
B4q B4e C♯5q C♯5e | D5e C♯5e B4e E5dq |
E5q C♯5e D5e E5e F♯5e | E5q C♯5e A♯4q A♯4e |
B4e A4e G♮4e F♯4q D5e | E5e D5e C♯5e B4dq
```

第 6 小节两个 A4 共用首个 A 前的升号。第 7 小节未重印升号，A4 随调号为自然音，同小节 G4 则印还原号。可要求确定 B 小调的局部进入与末尾收束。

### 2 · 四升，3/4

```text
G♯4q（弱起） | G♯4h G♯4q | E4h E♯4q |
F♯4q A4q C♯5q | B♯4h B♮4q | A♯4q A♮4q G♯4q |
F♯4q B4q B♯4q | C♯5q F♯5q C♯5q | A4h A4q |
G♮4q B4q E♯4q | F♯4h
```

保留 B 与 A 的升、还原变化。末两小节可比较 G♮ 的下属方向与 E♯ 的导音作用。

### 3 · 两降，C

```text
D5h D5q B♭4q | A4q C5q D5q A4q |
B♭4h B♭4q G4q | F♯4h F♮4h |
D5h C5q B♭4q | E♭5q D♭5q C5q A♭4q |
C5q B♭4q A♭4q D4q | G4h E4q G4q | C4w
```

比较 F♯ 后的还原与后段 D♭、A♭ 的结合。可先标出 G 的局部趋向，再配置向 C 的终止。

### 4 · 一降，2/4

```text
A4q G4e C5e | C5dq C♯5e | D5q G4e B♭4e |
A4q G4q | F4q E4e A4e | A4q B♮4e C♯5e |
D5dq C5e | B♭4h | C5q B♭4e A4e |
D5q C5e B♭4e | B♭4dq A4e | G4h
```

对照两次 C♯–D 与终止时的 G，分析目标调的属音怎样在中段获得强调。
