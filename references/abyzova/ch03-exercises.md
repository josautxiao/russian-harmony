# A 主题 3 带谱习题题面

A-048 为钢琴配和声题，印刷 32 页（PDF 18L）。A-049 为书面配和声题，第 1–2 小题在印刷 32 页，第 3–10 小题在印刷 33 页（PDF 18R）。本页仅录给定旋律。

记法为「音名和八度:以四分音符为 1 的时值」，中央 C=C4，# 为升、b 为降，竖线分小节。普通拍子的 C 记作 4/4。保留题面临时变音。两组在本章以主、下属、属原位三和弦为基本材料。从给定旋律判断调性、句界、终止与配置，安排功能后写其余声部。
