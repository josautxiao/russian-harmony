# B补充：综合习题

来源：B《Дополнение》，印刷428–435页，PDF424–431。印刷428页同时含上一章结尾与附录开头。此处是训练方法提炼，未把谱例OCR转换成可直接作答的题面。

附录提供较长旋律的综合配和声，常以简单二部或三部结构为背景，要求综合使用已学手段。解题先规划段落、终止、转调与回归，再安排模进、持续音、非和弦音等局部语汇，最后逐声部核验。

- 用户指定附录题时，先打开对应原页核对调号、拍号、全部音符与时值；若无法读取，只给训练步骤，不猜谱。
- 自编替代练习时明确标原创，给完整输入并标允许材料、目标形式和检查标准。
- 评价依据应覆盖结构与声部两个层面，不能以使用手段的数量代替音乐连贯性。
