# 教材 B · 俄罗斯音乐中的自然音调式

原书独立标题「Диатонические лады в русской музыке」，从印刷第 169 页（PDF 165）开始。以下使用体例中的小写 `t/d/s` 表示小调中的主、自然属与下属三和弦。正文以俄罗斯民歌及专业作曲家的自然小调写法为材料，并提到贝多芬第五交响曲第一乐章尾声也可听到自然小调下降模进。

## B-391 · 小属和弦及其收束作用

印刷第 170 页（PDF 166）。里姆斯基-科萨科夫《湖上柳树》（Над озером верба，《百首歌曲》Op. 24 No. 52），Andante，b 小调，7/4。谱上用两个八度线段记录高位织体，并以「конец」标出末段。首次记号 `d–t` 出现两次，续见 `dVII–s`；末段接 `dVII–d`，收束停在 F♯ 小三和弦。对照这个落点与强导音的属终止，教材在这里说明自然属可以充当句段甚至全曲的结束音响。

## B-392–393 · 下属和弦作结束音响

印刷第 171 页（PDF 167）。正文用 VI→V 的半音解释自然小调下属通向主音和弦的声部倾向，并指出 s 自身也可以是终点。

- B-392，塔涅耶夫所记录的俄罗斯民歌，无调号、3/2，末格谱下把 A4 标作 `t`，D5 标作 `s`。这是一条单线旋律，功能字母为原书提示。原谱四格按节奏读为：

~~~text
C5q E5q E5q D5e C5e D5e E5e F5q |
E5q E5q E5q D5e C5e D5q A4q |
C5q A4q A4q C5e E5e D5q A4q |
C5q A4q A4q C5e E5e D5h
~~~

- B-393，里姆斯基-科萨科夫《祝酒歌》（Заздравная，菲利波夫选集第 6 首），f♯ 小调、2/4。谱面用双线与「конец」分出末段。开头原标 `t–s–d₆–t`；末段为 `s₆–dVII–tsVI–s`，最后落 B 小三和弦。装饰音型在前后段回响，两处十六分的落点与下方八分和弦分别对读。

## B-394 · 自然小调中属、下属交错及不同结尾

印刷第 171 页（PDF 167），a 小调。八格四部自拟谱，女高／女低／男高／低音。无拍号，前五格短型以四分为主，第一、二、五、六、七、八格末用二分，第三、四格为五次四分起音。原谱同音共享以下依音响列出。

| 格 | 原标功能或所标片段 | 四部起音 |
|---|---|---|
| 1 | t–d–s₆–t | E4/C4/A3/A3 → G4/E4/B3/E3 → A4/D4/A3/F3 → E4/E4/C4/A3 |
| 2 | t–dVII–s₆–t | A4/E4/C4/A3 → B4/G4/D4/G3 → D5/A4/D4/F3 → E5/A4/C4/A3 |
| 3 | 中三拍 d–s₆–d₆ | E4/C4/A3/A3 → G4/E4/B3/E3 → D4/D4/A3/F3 → E4/B3/B3/G3 → E4/C4/A3/A3 |
| 4 | 中三拍 s–d–s₆ | E4/C4/A3/A3 → F4/D4/A3/D3 → G4/B3/G3/E3 → D4/D4/A3/F3 → E4/C4/A3/A3 |
| 5 | 末三拍 s–dtIII–t | E4/C4/A3/A3 → F4/D4/A3/D3 → G4/E4/C4/C3 → A4/E4/C4/A2 |
| 6 | 末两拍 dVII–t | E5/A4/C4/A3 → F5/A4/C4/F3 → D5/G4/B3/G3 → A4/E4/C4/A3 |
| 7 | 末两拍 dVII–d | C5/A4/E4/A3 → D5/A4/D4/F3 → D5/G4/B3/G3 → E5/G4/B3/E3 |
| 8 | 末两拍 d–s | C5/E4/A3/A3 → D5/G4/B3/G3 → E5/G4/B3/E3 → F5/A4/D4/D3 |

原书用不同括号突出不同片段。第 3、4 格主要对读夹在属或下属周围的三和弦，第 5–8 格对读以三度或二度根音关系收尾的变体。放大复核第 3 格第 3 击和第 4 格第 4 击，上谱 D4 共用符头，右侧向上、左侧向下各有符干。第 6 格低谱头两击的男高都是下谱第一条上加线上的 C4，第 3 击落到上方第一间 B3，末击回到 C4 二分，与低音 A3 的下符干分开。照此设计题面时，先固定自然音的 VII、自然小属与计划的闭合程度，再选择保留同样的括线位置。

## B-395 · 自然小调中的其他落点

印刷第 172 页（PDF 168）。里姆斯基-科萨科夫《雪姑娘》，a 小调、3/2。依谱下功能看 `d | t | dVII–t–s₆ | dtIII₆–t | s`。开头双低音由 E 进入 A，末格低谱下方 D、上方 D 形成八度，上谱用 A、F、D 的和弦层叠收束。教材举例说明同一节段可让自然属、III、VII、下属及主音各有清晰的局部位置，最后停在下属。

## B-396 · 同一变格旋律的和声变体

印刷第 172 页（PDF 168），a 小调。教材强调旋律四度跳进，在相同旋律外形下比较下属、重下属、自然属类和弦。按页从左到右、从上到下列十二格，每项为 S/A/T/B，常规以四分进入、二分收束。第 7 格另有女低 E4 四分落点。第 8 格有原印 `×`，正文列为带双重功能因素的特殊写法。

| 原分组和次序 | 原标 | 四部起音 |
|---|---|---|
| 1.1 | s₆–t | D5/D4/A3/F3 → A4/E4/C4/A3 |
| 1.2 | s–t | D5/F4/A3/D3 → A4/E4/C4/A3 |
| 1.3 | s₇–t | D5/F4/C4/D3 → A4/E4/C4/A3 |
| 2.1 | ss–t | D5/G4/B♭3/G3 → A4/E4/C4/A3 |
| 2.2 | ss₆–t | D5/G4/D4/B♭3 → A4/A4/E4/A3 |
| 3.1 | dVII₇–t | D5/F4/B♮3/G3 → A4/E4/C4/A3 |
| 3.2 | dVII₆–t | D5/G4/D4/B3 → A4/F4/C4/A3，女低续 E4q |
| 3.3 | d₇–t，× | D5/G4/B3/E3 → A4/E4/C4/A3 |
| 4.1 | s–t | F4/D4/A3/D3 → A4/E4/A3/A2 |
| 4.2 | dVII₆₄–t | G4/D4/B3/D3 → A4/E4/C4/A2 |
| 4.3 | ss₆₄–t | G4/D4/B♭3/D3 → A4/E4/A3/A2 |

第 2.2 格终点上谱只见一枚 A4 二分符头，按上两部合音标出。前三组的主要跳进为 D5→A4，末组在低音保存 D3→A2，供对照把四度放进低音与放在旋律中时的区别。移调时保留相对四度、指定和弦的转位及 B♭／B♮ 的功能差异；原创题可以固定一条跳进，要求分别给出完整、省音与同音收束。

## B-397–398 · 三度根音关系

印刷第 173–174 页（PDF 169–170）。

- B-397，巴拉基列夫《绵长歌》（Протяжная，第 32 首），g♯ 小调。根据谱下标记，主与关系大调和弦交替为 `t–dtIII–t–t–dtIII–s–t`。最后两格前后可见 5/4 至 3/4 的变化。教学位点是 t 与关系大调主和弦之间的功能交替。
- B-397а，原书四行文字谱 `t–dVII–tsVI–s`、`t–tsVI–s–d`、`t–dtIII–d–dVII`、`dVII–d–s–tsVI–t`。括线分别标出 `tsVI–s`、`t–tsVI`、`t–dtIII` 与 `d–dVII`、`dVII–d` 与 `s–tsVI`、`tsVI–t`。
- B-397б，正格 `d–dtIII–t` 和变格 `s–tsVI–t`。各段两根括线分别围住首两个、末两个和弦，显示一个四五度关系怎样由两个三度连接替代。
- B-398，柴科夫斯基《马泽帕》，g 小调、alla breve。上方长连线覆盖整句。谱下把 `t–tsVI–s` 与 `d–dtIII–t` 的三度链置于同一谱例。听辨低音 G→E♭→C 与 D→B♭→G，可将两条链分别还原为 t–s 和 d–t 骨架。

## B-399–402 · 二度根音关系及低音半音的替换

印刷第 174–175 页（PDF 170–171）。正文列 `dVII–t`、`t–dVII`、`dVII–tsVI`、`tsVI–dVII`、`d–s`、`s–d`、`s–dtIII`、`dtIII–s` 为典型关系。对较少见的 `d–tsVI` 半音关系，教材提出保留低音半音而换成 s₆，或保留两和弦并加上全音关系的后续链。

B-399，a 小调。四格均为 S/A/T/B。第二、四格无谱下功能字母，括号标签按所见和弦推定。

| 格 | 功能 | 四部起音 |
|---|---|---|
| 1 | dVII–t | B4/G4/D4/G3 → A4/E4/C4/A3 |
| 2 | （dVII–t） | D5/G4/B3/G3 → A4/E4/C4/A3 |
| 3 | d–s | E4/B3/G3/E3 → F4/D4/A3/D3 |
| 4 | （d–s₆） | G4/E4/B3/E3 → D4/D4/A3/F3 |

B-400，a 小调。a 两格保留 d–tsVI；б 前两格把 E3→F3 保留而换作 d–s₆，第三格反向；в 两格分别是 d–tsVI–dVII–t 与 tsVI–d–s–dVII–t。谱面主要起音如下，同一声部的中间八分用括号补列。

| 格 | 四部起音 |
|---|---|
| а1 | G4/E4/B3/E3 → A4/C4/A3/F3 |
| а2 | G5/G4/B3/E3 → C5/A4/A3/F3 |
| б1 | G4/E4/B3/E3 → A4/D4/A3/F3 |
| б2 | G5/G4/B3/E3 → D5/A4/A3/F3 |
| б3 | A4/A4/D4/F3 → E5/G4/B3/E3 |
| в1 | B4/G4/E4/E3（男高括注 D4 八分） → A4/F4/C4/F3 → G4/D4/B3/G3 → E4/C4/A3/A3 |
| в2 | C5/F4/A3/F3（女高过 D5 八分） → E5/G4/B3/E3 → F5/A4/D4/D3（男高过 C4 八分） → D5/G4/B3/G3 → A4/E4/C4/A3 |

B-400б 第三格上谱首柱 A4 的符头带上下符干。в1 的括号 D4 与前面的 E4 共用上方一条连梁，属于男高的可选八分；下谱末格 A3 与相邻墨线相贴，仍按共享音位存录。

- B-401，里姆斯基-科萨科夫《哎，落下，靠岸》（Ой, пала, причала），a 小调、4/4。原标三格依次是 `t–s₆–t | t₆–t–tsVI–t | t–dVII–tsVI–t`。第一格低音 A3–G3–F3–A3，第二格以 C4 开头，第三格让 G3→F3→D3→A3 经过。课堂可对照同一主音下两组不同的下行低音。
- B-402，里姆斯基-科萨科夫《雪姑娘》，C 大调、4/4。四分和弦以相近节奏作上下移动，第二格上谱换低音谱号。原印八个柱式旁各有数字「3」，高谱换低谱前后分别印在柱式上方或下方，按其原位置记录。下谱两个小节的最低声部分别为 C2–D2–E2–F2 与 G2–A2–D2–G2，每音四分，成对的下弧在第 1 格两对及第 2 格的首、末两对出现。作品用来听辨二度关系如何从小调语法扩展到自然大调。

## B-403–405 · 调式性和弦结构

印刷第 176–177 页（PDF 172–173）。正文提到省三音的二音和弦、单音及八度，以及声部进行较自由的四六合弦。B-403 前三格 a 小调，第四格 C 大调。各组按 S/A/T/B 排列，括线位置参看功能栏。

| 格 | 括线所标和声 | 四部起音 |
|---|---|---|
| 1 | 后两拍 dVII₆₄–t | E4/C4/A3/A3 → F4/D4/A3/D3 → G4/D4/B3/D3 → A4/E4/C4/A2 |
| 2 | 后两拍 dtIII₆₄–t | A4/D4/F3/D3 → C5/E4/G3/G2（男高两枚八分 G3–F3） → A4/C4/E3/A2 |
| 3 | 前三拍 dVII–s₆₄–dVII₆ | B4/G4/D4/G3 → A4/F4/D4/A3 → G4/D4/D4/B3 → A4/E4/C4/A3 |
| 4 | 前三拍 D₆–SII₆₄–D | G4/D4/G3/B2 → A4/D4/F3/A2 → B4/D4/G3/G2 → C5/C4/G3/E2 |

可用第三、四格在根位与六和弦之间对照经过四六，也可在第一、二格练以二度或三度根音关系连接四六至 t。改调时保留和弦功能的相对位置以及原设低音跳进。

- B-404，四组四度叠置的自然音七度和音。前三格用开符头、虚线和休止突出解决音程，第四格写成连续声部。原书列取自自然小调 I、IV、V 级及自然大调 II、III、VI 级的可能位置，一般由两外声各行三度、中声行二度，收至大三度。前三格密集加线和个别跨线虚线留作复核。
- B-405，民歌《征兵歌》（Рекрутская），教材注明取自皮亚特尼茨基 1914 年选集。三升，节拍 2/4→3/4→2/4。第一组上行的 B4–E5 置于 F♯4 上方，括注同时纵列 E5/B4/F♯4。后续的连线短型为其旋律化对照，括号叠置音为原书分析提示。教材提示在初级民歌配和声中谨慎采用这一结构。

## B-406–407 · 多利亚小调

印刷第 177–178 页（PDF 173–174）。多利亚的大六度为特征音。B-406 无调号，示范音列 `A4 B4 C5 D5 E5 F♯5 G5 A5`。印刷箭头标出 A 到 F♯ 的大六度，随后同时音为 D–F♯–A 的大下属（S）与 B–D–F♯ 的小三和弦（SII）。

原谱后分五格。前三格比较以 D 大三和弦通向 a 小三和弦的换位。第 1、3 格低部是 F♯3→A3，并在上部配合 D5→C5 或 D5→A4。第 2 格把根位 D 大三和弦接到以 C 为低音的 a 小三和弦。后两格原标 `S₆–d₆–t` 与 `S₆–SII₆–t`，是经自然属六或经 II 级六延展到 t 的两条方案。单高音谱表的少量合写声部可回看印刷页。

B-407，利亚普诺夫《圣三一节歌》（Троицкая，第 23 首），g 多利亚，2/4，教材题注「图式」。开端两格突出 `t–S`，低谱用 E♮ 显示 C 大三和弦；句后下谱标 `SII | t₆–d₇ | t₆–SII₆ | t₆`，终点保持 g 小调。正文指出，多利亚大下属可往 t、t₆、d 或经过小 II 级返 t；往 dVII 的情形常使 t 与 dVII 都有独立支点。移调时用相对于主音的大六度来保留区别，例如从 A 调 F♯ 改到 G 调 E♮。

## B-408–409 · 弗里吉亚小调

印刷第 178–179 页（PDF 174–175）。特征是低 II 级与 I 级相差半音。原书给出 `dtIII–dVII₆（小三和弦）–t`、`tsVI–dVII（小三和弦）–t`、`t–dVII₆（小三和弦）–s–t`。在这里，小 VII 指自然 VII 音作根的**小三和弦**，须结合旋律、低音及原谱变音判断。按教材举例，低 II 可经它的关系小三和弦到 t，末段低音可走 VII–I 全音或低 II–I 半音。文字另列里姆斯基-科萨科夫《姆拉达》中卢米尔的歌作参照。

B-408，a 弗里吉亚。原谱圈出 `A4–B♭4`，音列为 `A4 B♭4 C5 D5 E5 F5 G5 A5`。其后六格对读如下。第 2、3 格原谱无功能字母，和弦名按谱面推得。

| 格 | 功能或和弦 | 读谱位点 |
|---|---|---|
| 1 | 低 II–小 VII–t | B♭ 大三和弦–G 小三和弦–A 小三和弦；女高 F4–B♭4–A4，低音 B♭3–G3–A3 |
| 2 | （G 大三和弦–A 小三和弦） | B♮3 显示自然小调写法；女高 D5–A4，低音 G3–A3 |
| 3 | （G 小三和弦六和弦–A 小三和弦） | 同样的 D5–A4，B♭3–A3 让低音改走半音 |
| 4 | 小 VII₇–t | 女高由 D5 到 A4。小 VII₇ 由 D5/B♭4/F4/G3 构成，低谱男高 F4 接括号内 E4，两音以八分连梁相连。E4 的符头落在低谱第二条上加线上，随后同音在 t 上重新起奏。 |
| 5 | dtIII–小 VII₆–t | C 大三和弦起步，经过低音 B♭，女高最终到 A4 |
| 6 | tsVI–小 VII–t | F 大三和弦起步，第 7 级到主音的低音级进和女高位置分别可听 |

B-409，穆索尔斯基《在乡间》（В деревне），b 小调、4/4。上谱旋律为 `D5q A5q G5q F♯5e E5e | D5e B4e E5q B4h`，最后二分音带延长记号。原书在 E5 下有括注并标弗里吉亚 `dVII₆`，低谱 C♮–B 形成半音，末格落 t。这个原谱片段适合对照 B-408 第 2、3 格，分辨同样的旋律型如何换成低 II 级的低音。

印刷第 179 页下半转入自然大调与混合利底亚大调，先列自然大调常见的 `II–III–VI–IV` 与 `V–III–II–III–IV`，并指出主和弦与 II 级或关系小调主和弦的相对支点。

## B-410–412 · 自然大调的变格走法

印刷第 180 页（PDF 176）。

- B-410，柴科夫斯基《禁卫军》（Опричник），Allegro moderato，D 大调、4/4。首行可跟读 `T–TSVI | DTIII–D | T–D₆–TSVI | DTIII–T`，原下方括线把 DTIII–T 连成一组。第二行末格另标 `T–S₆–T`。同一段里可对照三度和低音级进两种收束。
- B-411，塔涅耶夫民歌改编选段，D 大调、4/4。谱面第一格是 D 八度持续，第二格继续保持并引入内声，后面两处标 `a`、`a1` 的括线供比较相近材料在两个位置的和声与低音变化。原页仅给选集类别，曲名留待由选集核对。
- B-412，C 大调，五格四部写作。次序为 S/A/T/B，下方的长音按谱面保留。

| 格 | 原标 | 四部起音 |
|---|---|---|

## B-413–414 · 混合利底亚大调

印刷第 181 页（PDF 177）。正文指出低 VII 使属三和弦为小三和弦，同时在低 VII 构成大三和弦。两者可直接入 T，也可经过 SII、TSVI 或 S。

|---|---|---|
| 1 | d–T | 上声部 B♭4→C5，小属直接入 T |
| 2 | dVII–T | B♭ 大三和弦直接入 T，同样看见上声部 B♭4→C5 |
