# 教材 B · 主题 49 · 大小调体系

来源为 1965 年版《Учебник гармонии》，印刷第 336 页（PDF 332）起。教材按主导的主和弦给出大调–小调或小调–大调体系，又按来源区分同主音（如 C 大与 c 小）和关系调（如 C 大与 a 小）。下列和弦按教材标记保存，列音按低至高。

## 大调借用同主音小调的下属组与属组

| 谱例 | 原谱与教学位点 |
|---|---|
| B-731 | 印刷第 336 页（PDF 332），C 大调。三组全音符纵向音高为 D4–F4–A♭4（sII）、F4–A♭4–C5（s）、A♭4–C5–E♭5（tsVI）。三度根音关系将下属组联结起来，A♭ 是三组共有的借用音。 |
| B-732 | 印刷第 337 页（PDF 333），同一 C 大调语境。三组为 E♭4–G4–B♭4（dtIII）、G4–B♭4–D5（d）、B♭4–D5–F5（dVII），都含 B♭。教材把整组与自然小调的属功能组对应。 |
| B-733 | 同页，格里格《在挪威山中》Op. 61 No. 6，C 大调、3/4、Allegretto，两系统。前两句用八分弱起，低谱双音附点二分跨小节延续。第二系统原标 dtIII₆–T–dtIII₆。dtIII₆ 的低音为 G3，E♭4 及两个八度的 B♭ 与低音 G3 组成降 III 级六和弦。第二系统两个 dtIII₆ 的起拍同为 G3–B♭3–E♭4–B♭4，高谱 B♭4 有上下符干两个同音声部。中间 T 的起拍纵列为 C3–G3–C4–E♮4–G4–C5，随后两降再现。 |
| B-734 | 同页，巴拉基列夫《看吧，我的朋友》，D 大调、12/8。原标 T–dVII–TSVI–S–T。复奏的八分和弦构成复拍，dVII 明写 C♮，为同主音 d 小调的自然 VII 级。借用和弦首次进入时，低谱与高谱各列 C♮–E–G，C♮3 与 C♮4 分别明写还原号。后半回到 B 小三和弦、G 大三和弦与 D 大调主音响。 |

教材允许借用 s、d 两组的三和弦、七和弦及转位，偶见九和弦。移调先确定大调主音，按降 VI 或降 VII 拼写借用音，再核对同主音小调中的功能及回归主调的连接。

## 小调借用同主音大调的属组与下属组

| 谱例 | 原谱与教学位点 |
|---|---|
| B-735 | 印刷第 338 页（PDF 334）。左栏 C 大调为 G4–B4–D5（D）、G4–B4–D5–F5（D₇）、B4–D5–F5（DVII）。中栏在 c 小调三降调号下重写相同三个音响，逐个还原 B。右栏 c 小调列出 DTIII（E♮4–G4–B♮4）、D（G4–B♮4–D5）、DVII（B♮4–D5–F5）。两个还原记号使 DTIII 成为小三和弦。 |
| B-736 | 同页，瓦格纳《帕西法尔》，c 小调、4/4、Molto lento，三格。原标 tsVI–s–DVII–tsVI₆₄–DTIII–t₆。末格前后对照低谱的 E♮2 与 E♭2，末格高谱为 B♮4q E♮4e. F♯4s G4h（s 为十六分），低谱先用 E♮2–B♮2 震音三拍，末拍改为 E♭2–G2 震音。G4 延伸至变音交界两侧；教材在两组震音下分别标 DTIII、t₆。 |
| B-737 | 同页，c 小调。三组全音符为 D4–F4–A♮4（SII）、F4–A♮4–C5（S）、A♮4–C5–E♮5（TSVI）。还原 A 贯穿三组，末组同时还原 E。 |
| B-738 | 同页，格里格《松树》Op. 59 No. 2，d 小调、6/8、Allegretto tranquillamente。八分弱起后，原标 t–S–t。首格后半低音改为 G2，第一处 S 的同响为 G2–B♮3–D4–G4–D5，B♮3 的还原号写在低内声，给出同主音 D 大调的下属和弦。次格起回 D 低部，后半重现 G 低音及内声 B♮，后两格回 D 低部并以高谱附点相接。 |
| B-739 | 同页，贝多芬钢琴奏鸣曲 Op. 110，f 小调、2/4、Allegro molto。原标 t₆–SII–K₆₄–D–tsVI–sII₆₅。第二格起拍为 G2–B♭2–D♮5，原标大写 SII。末格第二拍为 B♭2–F3–D♭5–G5，D♭5 明印降号，原标小写 sII₆₅。两个 II 级的三音同在高谱 D5 音位，分别写还原和降号。 |
| B-740 | 印刷第 339 页（PDF 335），普罗科菲耶夫《儿童音乐》，d 小调、4/4。原标 t–t₆–TSVI。最初上下两谱用相同节奏呈示动机，第三格起高谱有八度线。第五格低谱为 B♮1q D2e F♯2e B♮2e D3e F♯3e B♮3e。TSVI 原标在第二组八分起音 B♮2 下，B–D–F♯ 琶音上行，同一小节分别在新八度明印还原与升号。起始小主和弦与其第一转位都保留 d 小调底色。 |

## 借用和弦的副属、变音与不同终止

教材以具有主导地位的主和弦判定大调–小调或小调–大调。副属可引入两组借用和弦，扩大离调中心；小调–大调的相同用法较少见。增六重属与那不勒斯六和弦也可以从小调进入大调。

**B-741**，印刷第 339 页（PDF 335）。C 大调、2/4，双线划为三组，每组三格。以下按四声部复原。q、e、h 分别表示四分、八分、二分，~ 表示连音。每组教材标记依次为 D→tsVI–sII₇–D，T–D→dtIII–tsVI–T，T–D₂→s₆–dtIII₆–T。第一组降 E 大三和弦引向降 A，第二组降 B 大三和弦引向降 E，第三组 C₇/B♭ 引向 F 小三和弦第一转位。前两组分别在低音加入 D♭、A♭。

~~~text
1
S C5q B♭4q | A♭4q A♭4q | G4h
A G4q G4q | A♭4q F4q | D4h
T E4q E♭4q~ | E♭4q C4q | B3h
B C3q E♭3e D♭3e | C3q D3q | G3h
2
S C5q D5q | E♭5q C5q | C5h
A E4q F4q | E♭4q E♭4q | E♮4h
T G3q B♭3q~ | B♭3q A♭3q | G3h
B C3q B♭2e A♭2e | G2q A♭2q | C3h
3
S E5q E5q | F5q E♭5q | E♮5h
A G4q G4q | F4q G4q | G4h
T C4q C4q | C4q B♭3q | C4h
B C3q B♭3q | A♭3q G3q | C3h
~~~

前两组的第二拍副属含纵向导音，分别为 G、D。逐组复核副属后的第一纵列，分别为 C3–E♭4–A♭4–A♭4、G2–B♭3–E♭4–E♭5、A♭3–C4–F4–F5，都是借用三和弦第一转位。前两组以副属原位的低音根音经过下方全音后衔接转位。第三组副属的 E 上行到 F，低音 B♭ 下行到 A♭。第 3 组副属处内声 C4 与低声 B♭3 上下邻接。

**B-742**，印刷第 340 页（PDF 336），巴赫《平均律键盘曲集》第二卷降 B 小调赋格末两格，3/2。前格原注 b-moll，末格原注 B-dur。四声合为 B♭2–D♮4–F4–B♭4 的附点全音符，五降调号中的 D 特写还原。教材把这种末和弦换为同主音大三和弦的做法列为传统终止（皮卡第三度），并另外指出反向以小三和弦结束大调作品较罕见。

**B-743**，印刷第 341 页（PDF 337）。六段由双线断开。原谱起首 C 大调、2/4，第四段起 c 小调，最后一段换 3/4。

| 分段 | 原标与实际音响（低到高） |
|---|---|
| 1 | C 大调。G3–B3–G4–D5 → E♭3–B♭3–G4–E♭5（dtIII）→ C3–C4–G4–E♮5（T）。G4 以二分符头跨该格两个四分和弦。首拍无功能标记，正文以小属和降 III 同组说明该终止。 |
| 2 | D₇→tsVI。G3–D4–F4–B4 → A♭3–C4–E♭4–C5。 |
| 3 | tsVI→T。A♭2–A♭3–E♭4–C5 → C3–G3–E♮4–C5。正文另列 dVII→s₆→T 为变格连接。 |
| 4 | c 小调 t–S₇–t。C3–E♭4–G4–C5 → F3–E♭4–A♮4–C5 → C3–E♭4–G4–C5。E♭4 保持至第二拍，作借用下属七和弦的七音。 |
| 5 | t–S–t。C3–C4–E♭4–G4 → F2–A♮3–C4–F4 → C3–G3–C4–E♭4。低谱 A♮3 显示多利亚式变格连接。 |
| 6 | t–D–DTIII₆–t，3/4。C3–G3–E♭4–C5 → G2–B♮3–G4–D5 → G2–B♮3–G4–E♮5，最高声接 G5 八分音符 → C3–C4–G4–E♭5。G2 与 B♮3 两个四分重奏保持两拍，E♮5 和末格的 E♭5 标出借用与回归。 |

## 关系大小调及等音联系

| 谱例 | 原谱与教学位点 |
|---|---|
| B-744 | 印刷第 342 页（PDF 338），俄罗斯民歌《田野里有一条小路》，利涅娃集第二部第 6 首，4/4。原注 g 小调→B♭ 大调→g 小调。前两格低谱整小节休止，第三格后半低谱才从 B♭3 进入。低谱依次为两格全休止、Rh B♭3q. G3e、A3q G3q B♭3e. C4s B♭3e A3e，末格 G3h.；末格两声部都为附点二分。高谱开头以 B♭4–G4 的交替立足 g，第三格扩为 B♭4–D5–F5，末格两层分别落 G4、G3。同一两降音列中的旋律支点和声部进入帮助判断调式中心。 |
| B-745 | 同页，C 大调 s = F4–A♭4–C5，a 小调 D = E4–G♯4–B4，均用全音符呈示。A♭4 与 G♯4 等音，但分别是大调小下属的三音、小调的导音。 |
| B-746 | 同页。先列小下属与大属三和弦各一组，括号里给等音改写。随后 D4–F4–A♭4–C5 带括注 G♯4，下一纵列低音 A3、上层 E4–A4–C5。后组 E4–G♯4–B4–E5，随后低层 D4 并带括注 A♭4，末列 C4–G♮4–C5–E5。教材以三和弦、七和弦及转位说明两组亲缘。 |
| B-747 | 同页，贝多芬钢琴奏鸣曲 Op. 81，第一乐章，Allegro，E♭ 大调。两谱均用高音谱号。低谱长音 B♮3 与 D4 同起，旁印括注 C♭4，其空心符头在下加一线上，给出 B♮3 的等音写法。两份扫描均显示后一格降号所属的全音符在该加线下方，是另奏的 B♭3。上谱 G5、G4 从 B♮3 所在格跨线连到 B♭3 所在格。调用时以括注的 C♭4 比较关系小调导音和大调小下属三音。 |
| B-748 | 同页，穆索尔斯基《鲍里斯·戈杜诺夫》序幕，4/4、Meno mosso，原注 E♭ 大调与 c 小调。开头两层 G 跨线延续，再引入独立低音。低谱 C♭2–C♭3 与下一格 B♮1–B♮2 分占上下八度，两条虚弧分别跨线相连，两个音区均明确写出降号与还原号。配合 B-745 比较同一音高改写如何导向另一关系调。 |

## 口头题

印刷第 343 页（PDF 339）。题 1 在 A♭、D、F 大调列 d、s 两组借用音响。题 2 在 e、c♯、b♭ 小调列 D、S 两组借用音响。题 3 分十一项分析作品，其中第 в 项含两首。

| 原分项 | 作品与指定范围 |
|---|---|
| а | 里姆斯基-科萨科夫《萨德科》，第二场选段。 |
| б | 瓦格纳《唐豪瑟》中的《晚星之歌》。 |
| в | 李斯特《Il pensieroso》与歌曲《三个吉卜赛人》。 |
| г | 拉赫玛尼诺夫 E 大调《旋律》。 |
| д | 德彪西《月光》开头。 |
| е | 李斯特《巡礼之年》中的《威廉·退尔的礼拜堂》。 |
| ж | 巴拉基列夫《Мне ли, молодцу》。 |
| з | 普罗科菲耶夫《儿童音乐》之《悔恨》。 |
| и | 斯片迪亚罗夫《阿尔玛斯特》第三幕《少女之舞》。 |
| к | 谢罗夫《朱迪丝》中的《印度之歌》。 |
| л | 沃尔夫歌曲《我在梦中看见》，首个十一小节乐段。 |

原创出题可给定 E♭ 大调与 c 小调，要求学生写出 A♭–C♭–E♭ 与 G–B♮–D 的适当转位，用同一个钢琴键演奏 C♭ 与 B♮，再各奏目的调的主和弦，指出各自解决方向。
