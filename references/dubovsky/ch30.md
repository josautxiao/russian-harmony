# 教材 B 主题 30 · 重属和弦中的变音

印刷第 203–210 页（PDF 199–206），起于第 203 页下部。教材以半音变化加强调内的原有趋向，变音所指和弦成员写在和弦标记之前，如 `♯₅D₇` 或 `♭₃DVII₄₃`。

## B-450–451 · 增六音程和变音重属组

印刷第 204 页（PDF 200）。B-450 的低音为同主音小调或和声大调的低 VI，高音为升 IV。c 小调及 C 大调两例均呈 A♭4–F♯5：前者的 A♭ 见调号，后者写为临时变音。

B-451 在这对外音之间加一或两个音。原页上谱 c 小调、下谱 C 大调。表中列按低到高的音级集合。

| 原名 | C 大调实音 | c 小调的记载 |
|---|---|---|
| 增六和弦 | A♭–C–F♯ | 同一组音，A♭ 随调号 |
| 增三四和弦 | A♭–C–D–F♯ | 同一组音 |
| 双增三四和弦 | A♭–C–D♯–F♯ | 原谱写「无」 |
| 增五六和弦 | A♭–C–E♭–F♯ | 同一组音，E♭ 随调号 |
| 双增五六和弦 | A♭–C–E–F♯ | 原谱写「极少见」。右侧小符头在高谱顶线，带降号，读 F♭5，与大调行的 E5 同键 |

教材说作曲中常用低端 A♭ 在低音的形态。下一节另给低升 IV 形成减三度的少见排列。出题应保留增六上下端的拼写及解决倾向。

## B-452–455 · 准备增六重属

印刷第 204–205 页（PDF 200–201）。可由主三和弦及其转位或 S 组进入。常把 VI 或低 VI 放在低音，便于得到常用的增六排列。

B-452，四种准备写法。按 S/A/T/B，括号列原谱的低音可选降号及末格高音等音提示。

| 格 | 原起始功能 | 四部起音 |
|---|---|---|
| 1 | S(s)₆ | F5/C5/C4/A3（或 A♭3） → F♯5/C5/C4/A♭3 |
| 2 | TSVI | C5/E4/C4/A3 → D5/F♯4/C4/A♭3 |
| 3 | S(s)₆ | C5/F4/C4/A3（或 A♭3） → D5/F♯4/C4/A♭3 |
| 4 | S(s)II₄₃ | D5/F4/C4/A3（或 A♭3） → D♯5（括注 E♭5）/F♯4/C4/A♭3 |

B-453，贝多芬钢琴奏鸣曲 Op. 13 终乐章，E♭ 大调、4/4。末段原标 `S₆–♭₅DD₄₃ | D`，低部从自然音半音下降，接属的低音。注意此处印刷记号指重属的五音降低。

B-454，c 小调。两格按所见和声起点列 S/A/T/B：

| 格 | 原标 | 四部起音 |
|---|---|---|
| 1 | SII₆–DDVII₇ | D5/A♭4/F4/F3 → C5/A♭4/E♭4/F♯3 |
| 2 | s–DD₆₅ | A♭4/F4/C4/F3 → A♭4/D4/C4/F♯3 |

两格均是 F3→F♯3，以低音升 IV 和上方 A♭ 形成减三度。第 1 格首柱男高 F4 位于低音谱表第二条上加线上方的间内，下一柱男高 E♭4 回到第二条上加线。

B-455，贝多芬钢琴奏鸣曲 Op. 7，3/4。原标引入 `DDVII₆–♭₅DD₄₃–K₆₄–D₇–T`。连续两种重属中出现临时降音，低音向终止四六推进；旋律在 K₆₄ 周围有装饰。教材以此说明普通重属可在半音低音中准备变音重属。

印刷第 205 页末提出下一步的解决原则：增六两端向八度展开，减三度依排列进八度或同音，其余声部平稳，共同音保持。

## B-456–460 · 终止四六、经过主四六和直接入属

印刷第 206–207 页（PDF 202–203）。B-456 的六格都写在 C 大调。最常用的是向终止四六，双增三四和双增五六在本节只这样解决；末格给带六度的属。音位表按 S/A/T/B 排列。同谱表的共享或附注单列。

| 格 | 四部起音与原谱提示 |
|---|---|
| 1 | C4/C4/F♯3/A♭2 → E4/C4/G3/G2，起首两上部共用 C4 |
| 2 | D5/F♯4/C4/A♭3 → E5/G4/C4/G3 |
| 3 | C5/F♯4/D♯4/A♭3 → C5/G4/E4/G3 |
| 4 | F♯4/E♭4/C4/A♭3 → G4/E4/C4/G3，右端 E4 旁有括号降记号供变体 |
| 5 | E5/F♯4/C4/A♭3 → E5/G4/C4/G3 |
| 6 | D♯5/F♯4/C4/A♭3 → E5/G4/B3/G3，原标 DT₍III₎₆ 的位置用于对照带六度的属 |

第 4 格右端的降记号为原小幅括注，正文语境也包含小调，因此保留 E♮ 与 E♭ 两种读法的区别。第 6 格原印功能下标笔画细，优先以实音、正文并读。正常增六的上下端 F♯ 和 A♭ 在本调解决到 G；减三度排列同理。

- B-457，贝多芬第五交响曲，C 大调、3/8。原谱八度线跨过增六与 K₆₄。印刷标 `♭₃DDVII₆₅–K₆₄`，低谱在解决处加厚，注意两端半音走向。
- B-458，三组自拟的直接入属写法。教材说明增六、增三四、增五六可以直接进属三和弦。第 3 格低谱括注及上谱 D♯→E 的标记留作对照。
- B-459，莫扎特《费加罗的婚礼》，f 小调、6/8。原标 DD→D，低谱虚线与数字 5 指出直接解决中低音和一个内声的平行纯五度。教材在这个条件下接受「莫扎特五度」，并给两种规避办法，一是先把增五六转成增三四，二是去带六度的属，偶尔用变音属。
### B-460 · 避开直接解决中的平行五度

印刷第 207 页（PDF 203）顶端。三组方案和最后一个收束音响用双纵线分隔。无拍号，以下按上谱上、下符干及下谱上、下符干列录，h、w 为二分、全音符；逗号隔同一层内的连续音符。

| 位置 | 上谱上声 | 上谱下声 | 下谱上声 | 下谱下声 |
|---|---|---|---|---|
| 第 1 组 | F♯5w → G5w | C5w → B4w | E♭4h、D4h → D4w | A♭3w → G3w |
| 第 2 组 | F♯5w → G5h、E5h | C5w → B4h~B4h | E♭4w → E♮4h、G4h | A♭3w → G3w |
| 第 3 组 | D♯5w → E5w | F♯4w → G4h、F♮4h | C4w → B3w | A♭2w → G2w |
| 收束 | C5w | E4w | G3w | C3w |

前两组保留 F♯5–G5 与 A♭3–G3，中层分别用 D4 的预先进入和 E♭4–E♮4 的半音改变来调整解决。第三组保留 A♭2–G2，观察 C4–B3 与 D♯5–E5 的反向运动。第 1 组低谱下方的短弧从 A♭3 全音符附近起，向右收在 D4 二分符号下方，弧的两端未印同音，存作原印连接标记。最右一列的低谱 D4、G3 两个全音符之后另有右括号。

## B-466 · 补充的两种变音和普通重属关系

印刷第 210 页（PDF 206）上部，C 大调。正文举鲍罗丁《伊戈尔王子》康恰科芙娜咏叹调末段为同类用法。以下依谱面符头分组，w 为全音符，h 为二分，~ 为同音延长。

~~~text
第 1 组
S E5w E♭5w D5w E♭5w
A G4w F♯4w~ F♯4w~ F♯4w
T C4w C4w~ C4w~ C4w
B C3w A♭2w A♮2w A♭2w

第 2 组
S E5w E♭5w D5w D♯5w E5w
A G4w F♯4w~ F♯4w F♮4w E4w
T C4w C4w C4w B♭3w G3w
B C4w A♭3w A♮3w A3h G3h C3w
~~~

第一组主和弦低音为 C3，随后 A♭2–A♮2–A♭2 交替，男高 C4 保持。第二组开头低谱并列两个 C4 全音符。变音重属经普通重属接变音属时，上谱 D♯、F♮ 同时出现，低谱末段由 A3、G3 两个二分音符导向 C3。
