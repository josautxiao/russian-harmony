# 教材 B 主题 21 · II 级七和弦

印刷第 125 页（PDF 121）起。原书称 II 级七和弦为下属七和弦，标 SⅡ₇，小调标 sⅡ₇。以下四部配置按女高／女低／男高／低音。

## B-281–282 · 构成和三种转位

印刷第 126 页（PDF 122）。

- B-281，C 自然大调为 D4–F4–A4–C5，根音到上三个音为小三度、纯五度、小七度。c 小调或 C 和声大调为 D4–F4–A♭4–C5，五度改为减五度。
- B-282，C 大调记法，自低至高为 SⅡ₇ `D4/F4/A4/C5`、SⅡ₆₅ `F4/A4/C5/D5`、SⅡ₄₃ `A4/C5/D5/F5`、SⅡ₂ `C5/D5/F5/A5`。小调的 A♭ 以括注降号示出。正文以 SⅡ₆₅ 最常用，它同时包含 S 的 F–A–C 和 II₆ 的 F–A–D，可视为下属加六。

准备可接在 T、T₆、T₆₄、S、S₆、TSⅥ 后，多作和声连接并准备七音；接 SⅡ、SⅡ₆ 时可有经过式七音。

## B-283 · 解决至属三和弦的八格

印刷第 127 页（PDF 123），C 大调音名如下。括号降号对应小调的 A♭。

| 格 | 连接 | 声部配置 |
|---|---|---|
| 1 | SⅡ₇→D | F4/C4/A3/D3 → D4/B3/G3/G3 |
| 2 | SⅡ₇→D | A4/C4/F3/D2 → G4/B3/D3/G2 |
| 3 | SⅡ₆₅→D | D4/C4/A3/F2 → D4/B3/G3/G2 |
| 4 | SⅡ₆₅→D | C5/D4/A3/F2 → B4/D4/G3/G2 |
| 5 | SⅡ₄₃→D | C5/F4/D4/A3 → B4/G4/D4/G3 |
| 6 | SⅡ₄₃→D | D5/C5/F4/A3 → D5/B4/G4/G3 |
| 7 | SⅡ₂→D₆ | A4/D4/F3/C3 → G4/D4/G3/B2 |
| 8 | SⅡ₂→D₆ | F5/A4/D4/C3 → G5/G4/D4/B2 |

第 1 格末低谱仅见位于顶线下方的 G3 符头与上行符干。表中的男高和低音同奏 G3 是四声部配列解读，无法从图中独立核定第二根符干。七音 C 下行到 B，五音 A（或 A♭）下行到 G。三音 F 通常上行到 G，在原位七和弦中也可下行三度到 D。根音 D 如在上三部通常保持，如在低音则跳至属根 G。

## B-284–285 · 进入终止四六，保持七音

印刷第 127 页（PDF 123）。B-284 为 C 大调四个并列样式，括号降号供降 VI 时采用。虚弧标同部保留 C，C 随后成为 K₆₄ 在低音 G 上方的四度。

| 格 | 连接 | 声部配置 |
|---|---|---|
| 1 | SⅡ₇→K₆₄ | F5/A4/C4/D3 → E5/G4/C4/G3 |
| 2 | SⅡ₆₅→K₆₄ | D5/A4/C4/F3 → E5/G4/C4/G3 |
| 3 | SⅡ₄₃→K₆₄ | C5/F4/D4/A3 → C5/G4/E4/G3 |
| 4 | SⅡ₆₅→K₆₄ | A5/C5/D4/F3 → G5/C5/E4/G3 |

B-285，柴科夫斯基《Соловушка》，Andante molto，e 小调，3/4。原标 `SⅡ₆₅ | K₆₄ | D | t`。第一格两个四分为 C5/E4/F♯3/A2，后三格各为附点二分，依次是 B4/E4/G3/B2、B4/D♯4/F♯3/B2、E4/E3。E4 在前两个不同和弦间保持，进入 D 时下行 D♯4，最后回到 E4。

## B-286–287 · 接主和弦和作品中的变格解决

印刷第 128 页（PDF 124）。B-286 自左至右为 `SⅡ₇–T₆` 两格、`SⅡ₆₅–T` 两格、`SⅡ₆₅–T₆`、`SⅡ₆₅–T₆₄–S₆`、`SⅡ₄₃–T₆₄–D₂`。前两格低音 D3→E3，第三、四格 F3→C3，第五格 F3→E3，第六格 F3→G3→A♭3，第七格 A♭3→G3→F3。与接 D 不同，这些接 T 的格保留七音 C。正文另称 SⅡ₄₃ 较少接原位 T。

B-287，柴科夫斯基《Он так меня любил》，Op. 28 No. 4，三降调号，4/4，c 小调。原谱以小写 t 标主和弦，分别把 sⅡ₄₃、sⅡ₆₅ 放在不同的回主接缝。开头由 s 到 sⅡ₄₃ 再到 t；接下来原标 s₆–sⅡ₆₅–t₆；末段经 sⅡ₄₃ 收到 t，上下两谱末休止皆带延长。谱中伴奏层分解有连线，功能标注落在实质换和弦处。

## B-288 · 解决中的跳进

印刷第 128 页（PDF 124），C 大调。七格依次是 `SⅡ₆₅–D`、`SⅡ₄₃–D`、两格 `SⅡ₂–D₆`、`SⅡ₇–T₆`、`SⅡ₇–K₆₄`、`SⅡ₆₅–T₆`。谱中斜线指明跳进，弧线指明相应的保持音。写作条件为七音下行一级或保持，外声部避免隐伏五度及八度。第六格以低音 D3→G2 和女高 A4→E4 的跳进到终止四六，同时保留女低 C4。

## B-289–290 · II 级七和弦与属七的转位对应

印刷第 128–129 页（PDF 124–125）。B-289 的十字图上下为 7 与 ₄₃，左右为 ₂ 与 ₆₅。B-290 把四个对应逐一写成四部。以下为 C 大调配置，小调按括注调号处理，D 的 B 按谱还原。

| 格 | 原标 | 声部配置 |
|---|---|---|
| 1 | SⅡ₇→D₄₃ | C5/F4/A3/D3 → B4/F4/G3/D3 |
| 2 | SⅡ₄₃→D₇ | D5/F4/C4/A3 → D5/F4/B3/G3 |
| 3 | SⅡ₆₅→D₂ | A5/C5/D4/F3 → G5/B4/D4/F3 |
| 4 | SⅡ₂→D₆₅ | F5/A4/D4/C3 → F5/G4/D4/B2 |

D 和 F 两音保持。C 下行 B，A 或 A♭ 下行 G。SⅡ₇ 的三音 F 变为 D₇ 的七音，两个七和弦连续时可由此听辨准备关系。

## B-291–292 · 低音跳进和经过连接

印刷第 129 页（PDF 125）。

- B-291，三格均为原位 SⅡ₇→省五音的 D₇。低音 D3→G3、D2→G2、D3→G2，按原图保留四度上行或五度下行；F 保持为后一和弦的七音。
- B-292，C 大调或小调，2/4。四格原标为 `SⅡ₆₅–T₆–SⅡ₇`、`SⅡ₆₅–T₆–D₄₃`、`SⅡ₆₅–TSⅥ₆₄–SⅡ₇`、`SⅡ₄₃–T₆₄–S`。前三组低音 F3–E3–D3，末组 A3–G3–F3（小调 A♭3）。前三组前两和弦各四分，末和弦二分。最后一组女低在经过 T₆₄ 两侧延续 C5 音位，低音仍逐级下降。既可在同一功能范围内配经过和声，也可以接到另一功能组。

第 129 页末引出 SⅡ₂。它常由原位 SⅡ 引入，七音在低音中作经过音，后接 D₆ 或 D₆₅。

## B-293、B-293а · 辅助性的 II 级二和弦

印刷第 130 页（PDF 126）。B-293 为 C 大调、2/4，`T–SⅡ₂ | T`。低音保持 C3，前三声部依次是 E4/C4/G3（附点四分）、F4/D4/A3（八分）、E4/C4/G3（二分）。由此可在持续主音上作辅助运动。

B-293а，达尔戈梅日斯基《Ночной зефир》，Allegro moderato，C 大调，3/4。四格原标 `T | T | SⅡ₂ | T`。低谱 C2/C3 八度在各格前两拍重复，第三拍休止，第三格上方出现 II 级七和弦后仍回 T。教材同时允许在给定声部符合解决条件时用 SⅡ₇ 或转位代替 S、SⅡ；若旋律的 II 级需要下行二度或三度，通常改用没有七音的 SⅡ₆。
