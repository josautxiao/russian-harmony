# 教材 B 主题 4 · 用正三和弦为旋律配和声

印刷第 30–31 页（PDF 26–27）引入给定旋律或低音的配和声。原书建议按前后功能给旋律音在 T、S、D 中定位。通常用主和弦起止，属和弦起始多在弱起，下属起始少见。弱拍进入的和弦一般在下一强拍换和声，强拍已经进入的和弦可以延长。逐对核查声部连接，低音以约一至一个半八度的波浪形线条为常态，并避免连续同向的五度跳进。

## B-057 · 八小节女高给定

印刷第 31 页（PDF 27）。无调号，2/4。每小节以竖线分开，括号内为时值。

G4（二分）｜A4 G4（四分）｜G4 F4（四分）｜D4（二分）｜D4 C4（四分）｜D4 E4（四分）｜F4 D4（四分）｜C4（二分）

这是下页写作示范的给定声部。调用时先保留八小节的音高、时值与重拍，再沿下文核对原书的分析和完整配列。

## B-058 至 B-065 · 配和声过程与被排除的方案

第 58–60 号在印刷第 32 页（PDF 28），第 61–64 号在第 33 页（PDF 29），第 65 号在第 34 页（PDF 30）。第 58、59 号仍呈现八小节旋律，第 60–65 号聚焦前四小节。四部音高顺序为女高、女低、男高、低音。第 66 号表格保留这些示范逐次补入的全部四部音高。

| 编号 | 页图上的写法和教材的理由 |
|---|---|
| B-058 | C 大调。首音 G4 是 T 的五音或 D 的根音，次音 A4 在正三和弦中只能取 S 的三音。以 D 开始会紧接 S，故教材选择 T，先填 G4/E4/C4/C3 二分。教材因给定旋律较低而选密集排列，末 C4 下预标 T。 |
| B-059 | 第 2 小节首拍填 A4/F4/C4/F3。上两部由 G4/E4 上行，男高 C4 留在原声部，构成 T–S 的和声连接。 |
| B-060 | 第 2 小节第二拍至第 3 小节第二拍暂标 T–D–S。教材随后排除此案。弱拍 G4 与下一强拍 G4 相同而换功能后，第 3 小节出现 D–S，且低音 G→F 与旋律 G→F 同向，不能按本章规则完成反向连接。 |
| B-061 | 将同三处改为 D–T–S。书上先标功能，内声部仍留给下一步。 |
| B-062 | 添第 2 小节末拍 D，G4/D4/B3/G3。低音 F3 上行到 G3，三个上声部反向下行，构成 S–D 的旋律连接。 |
| B-063 | 添第 3 小节首拍 T，G4/E4/C4/C3。共同音 G4 留在女高，构成 D–T 的和声连接。 |
| B-064 | 添第 3 小节第二拍 S，F4/C4/A3/F3。低音上行、上三部下行，构成 T–S 的旋律连接。 |
| B-065 | 第 4 小节 D4 是 D 的五音，填 D4/B3/G3/G3 二分。低音级进向上，三个上声部反向下行，男高与低音共用 G3。 |

## B-066 · 密集排列的四部完整示范，两种收尾

|---|---|---|---|
