# 教材 B 主题 8 · 终止式、乐段与乐句

印刷第 45–53 页（PDF 41–49）。本章的 период 是陈述一个音乐主题的乐段，предложение 是其中的乐句。典型练习为 4+4 小节，教材也列一体式、等长非四方以及不等长两句。先定位分句停顿与中间、结尾终止，再判断功能和收束强度。中间终止常停在 D 或 S，结尾常回 T。结尾接在正格终止后的附加变格终止要另外标出。

## B-097 · 完全与不完全终止的九组四部对照

印刷第 50 页（PDF 46），C 大调。原书此处的「完全」要求末 T 在强拍、根音置于女高，且前一 D 或 S 为原位。末 T 在弱拍、三音或五音置顶，或前一 D、S 为转位，均可降低完结性。以下按女高、女低、男高、低音记录。末 T 大多用二分，第 4、5 组不完全终止的最后一格是持续 T 中的旋律位置或配列改变。

| 原图 | 组 | 配置 |
|---|---|---|
| 完全 | а | B4/G4/D4/G3 → C5/G4/E4/C3 |
| 完全 | б | B4/G4/D4/G3 → D5/G4/B3/G2 → C5/E4/G3/C3 |
| 完全 | в | A4/F4/C4/F3 → C5/G4/E4/C3 |
| 完全 | г | C5/F4/A3/F2 → B4/D4/G3/G2 → C5/E4/G3/C3 |
| 不完全 | а | G4/D4/B3/G2 → G4/E4/C4/C3 |
| 不完全 | б | F5/A4/C4/F3 → E5/G4/C4/C3 |
| 不完全 | в | D5/G4/D4/B2 → C5/G4/E4/C3 |
| 不完全 | г | A4/F4/C4/F3 → G4/E4/C4/C3 → C5/E4/G3/C3 |
| 不完全 | д | C5/A4/F4/F3 → B4/G4/D4/G3 → C5/G4/E4/C3 |

下排前两组末女高分别为主五音与主三音，第三组的属和弦低音 B2 为三音。第四、五组应以 T **进入时**的拍位或最高音判终止，随后出现的高音 C5 属于已进入的 T。

## B-098 · 同一乐段内的不完全、完全终止

印刷第 51 页（PDF 47）。莫扎特《Тоска по весне》，F 大调，6/8，低谱下标「схема」，为教材和声简图。两道上方弧线分句。第一终止主和弦上置 A4，与下层 F4 同时出现，原标不完全。第二终止上置 F4，原标完全。比较两句相近的开头节奏和回主时的不同旋律位置。

## B-101 · 续写第二乐句并配和声

印刷第 53 页（PDF 49）。两升，4/4。括线标「第一乐句」。保留一个四分弱起，末小节三个四分的长度与开头互补。

F♯5 ｜ F♯5 E5h C♯5 ｜ D5 C♯5 B4 A♯4 ｜ B4h G4h ｜ F♯4h.

选择与第一句相应的节奏关系，并规划第二句的终止。给定的首句整行保持为题面。
