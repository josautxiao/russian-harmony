# 教材 B · 主题 54 · 经同主音主和弦转调

来源为 1965 年版《Учебник гармонии》，印刷第 373 页（PDF 369）起。

## 同主音主和弦的引入

教材列三种引入方式。第一种在句读处分隔同主音大小调的两个段落，常用相似开头形成对照。第二种让小调段以同主音大三和弦结束，正文举李斯特《罗蕾莱》。第三种先延长两个调可共用的不稳定功能，如小九度的 D₉、D₇、减导七、D，较少用小下属组等音响，再进入同主音调。

| 谱例 | 原谱与教学位点 |
|---|---|
| B-795 | 印刷第 373 页（PDF 369），梅耶贝尔《胡格诺教徒》，3/8、三降。第一个系统标 C-dur，起初 ff，首个 C 大调复奏纵列的高谱自下而上为 E♮4–G4–C5，低谱也明写还原 E；一连串强奏的和弦后先休止，再低声 pp 弱起转入第二系统 c-moll。上谱在 pp 弱起前改低音谱号，两谱随后均用低音谱。新段首格的上层低音谱以 E♭3 与 C4 为可辨骨架，重复附点八分、十六分、八分的节奏，音区、力度、主三音和段落开头形成对照。 |
| B-796 | 第 373 页底至第 374 页（PDF 369–370）顶，贝多芬 f 小调钢琴奏鸣曲 Op. 57 第一乐章。教材在首系统标 As-dur, moll，原标 T–D₄₃–T₆，通过分解音型延长属区。次页首格出现多处降号，原标 s 及降 II 六和弦；随即括线圈出 K₆₄–D₇，之后左手休止，右手有连续颤音。教学取点是共用属功能的延长如何让大、小两种 A♭ 主和弦衔接。续页原印 s、♭1sII₆，后两个功能以同一括线圈住。K₆₄ 与 D₇ 的最低声部都落 E♭3，上层改换，D₇ 上方印颤音。续后高加线颤音的完整音高仍待复核。 |

## 同主音主和弦作为中介

印刷第 374 页（PDF 370）的无编号箭头图。大调先转进同主音小调，再用小主三和弦的双重功能通向第一关系大调；反向操作可由小调先转同主音大调。

| 原图路线 | 共同和弦及其目标功能 |
|---|---|
| C→c→E♭ | C–E♭–G 为 c 的 t、E♭ 的 VI。 |
| C→c→A♭ | C–E♭–G 为 c 的 t、A♭ 的 III。 |
| C→c→B♭ | C–E♭–G 为 c 的 t、B♭ 的 II。 |
| c→C→a | C–E–G 为 C 的 T、a 的 III。 |
| c→C→e | C–E–G 为 C 的 T、e 的 VI。 |
| c→C→d | C–E–G 为 C 的 T、d 的自然 VII。 |

**B-797**，第 374 页底至第 375 页（PDF 370–371）上两系统，格林卡《鲁斯兰与柳德米拉》。谱面保留两升，起点方框 F，大幅用还原号、降号；首系统的低部和弦常分离为奏音、休止，原印 S、T、D。续页第一系统先印 T，第四格在 F 的低音处标 t，下一格 B♭ 低部为小下属 s。再下一系统方框 A♭，f 的 t 与 A♭ 的 TSVI 并标，后续 DD、D、T。分析路线因此为 F→f→A♭。续页第二系统方框后的 t／TSVI 对位，下谱明确同时写 A♭2 和 A♭3，转调支点以三音为低音。用连接处的 F–A♭–C 和终止来标记过渡，原谱的极高加线和密集声部可回查。

**B-798**，印刷第 375 页（PDF 371）下两系统，贝多芬第六交响曲第二乐章，12/8。开头方框 G，原标 SII₆、SII₆₅、DDVII₇，下一格为 D，后半标七音。次系统先印 T、D₇，随后低部与上层临时降号共同引出 g 小主音响。该处标 t，并在 E♭ 方框旁标 DTIII；后续 T₆、D₄₃ 与 T。第二系统转接处的低层 G2 进入后，低谱上声为 B♭3，高谱能辨 G4 与 D5。教材把该 g 小三和弦分别标 t 与 E♭ 大调的 DTIII。随后标 T₆，末格低层两个八度为 E♭2、E♭3，支持 G→g→E♭。颤音、叠置装饰音、短音以及低谱临时号留回查。

第 375 页末还提出先转入**目的调**的同主音调。教材举贝多芬 Op. 53 开头 C→e→E，及 Op. 10 No. 1 再现部 F→f→c。用于原创题可规定中介和弦的三音何处变更，再比较到达过渡调之后的一次离调与到达目的调之后的终止。

## 口头分析

印刷第 376 页（PDF 372）。教材要求分析前两个作品例 B-797、798 和本页 B-799 的转调手法，另列瓦格纳《罗恩格林》中艾尔莎的咏叹调，以及柴科夫斯基钢琴奏鸣曲第一乐章由主部转向副部的段落。

**B-799**，李斯特《当我看见繁茂的草地》（教材题名《Коль вижу я пышный луг》），6/8，声乐与钢琴三行谱，两系统。第一系统三降，声乐起句包含 E♭5 与 D5，伴奏用持续的十六分分解织体。跨系统转到无调号，声乐起句的节奏形态再现，伴奏同样维持分解型。第二系统首格，声乐为八分休止后 C5–B4–A4–C5–E5，低谱同时为 C4–A3–C4–E4–C4–A3，各为八分。分析上，该低层铺开 a 小三和弦。第二格钢琴内声出现 G♯4，末格声乐和内声的变音继续把听觉引向新调。可把跨系统前后各半小节的低音和三音并排，先识别同主音变化，再判断后续离调。钢琴密集内声、末格临时号和具体的双重功能留复核。

续写的教材条件为完成乐段、经同主音 d 小调在尾部转到 B♭ 大调、用 B♭ 持续音巩固新调。可把 d 的小主三和弦作为 B♭ 的 III，或在 d 调内先落 B♭ 大三和弦再重释。两条四部解决均是派生方案。

**钢琴题**同页，要求即兴演奏通过同主音主和弦转调的构造。教材给 C→c→A♭、C→c→B♭、a→A→f♯、a→A→b 四条示例路线，可按同一思路移调。演奏时可在进入中介调时保留主音并明确改变三音，随后在终点完成终止。
