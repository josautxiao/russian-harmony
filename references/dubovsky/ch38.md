# 教材 B · 主题 38 · 单声部自然音经过音

来源为杜波夫斯基、叶甫谢耶夫、斯波索宾、索科洛夫合编《Учебник гармонии》，1965 年版，印刷第 260 页（PDF 256）下半页起。

教材把经过音放在两个不同的相邻和弦音之间，通过大二度或小二度逐级同向连接。经过点通常在较弱位置，也可在相对强位。两个端点可属同一和弦的不同配置，也可随和声更换。自然音列上三度间可填一个音，四度间可填两个音。

| 谱例 | 原谱与教学位点 |
|---|---|
| B-570 | 印刷第 260 页。C 大调，3/4。两组女高分别 C5–D5–E5 和 E4–F4–G4，都是八分、八分、二分。十字符号标 D5 和 F4，左组 T–T，右组 T–D₆。 |
| B-571 | 印刷第 261 页（PDF 257）。吕利《吉格》，e 小调，12/8。前两格上方多个十字落在八分线条中，例如第一小组三音的 E4–F♯4–G4 进路；第三格稍后同类线条换到低谱。下方标 t–D₆／₆₅、t–d₆、s₆–D，比较升导音和其还原处。原谱十字点明弱位经过音。 |
| B-572 | 同页。贝多芬小提琴协奏曲 Op. 61，Allegro，D 大调，4/4。首次从 F♯4 经 G4 到 A4 填三度，再从 A4 经 B4、C♯5 到 D5 填四度。三个十字对应填入的音，谱下斜字标三度与四度跨度。 |
| B-573 | 同页。C 大调、3/4。谱例的上声部是 `G4q C5q~ | C5q B4e C5e D5q`，原弧为虚线。T 末 C5 延入 D 的较强拍，印「з」（延留）。后一个 C5 在 B4 与 D5 中间的较弱八分位置，印「п」（经过）。 |

原创题可用相同音高设计两个拍位，把前一和弦音持续到强拍作延留，再用同一音高填两个目标音之间的弱位。移调时保留音程方向、端点关系和节拍位置。下接印刷第 262 页。

## B-574–579 · 时值、三音配置、同度和七音

印刷第 262–263 页（PDF 258–259）。经过音通常等于或短于前一和弦音。能够听成经过七音、九音者可取较长值。通常的重音、重音程和和弦三音配置仍适用。主三和弦的三音有人接替时，让原声部及时转开。三音离开后也可由其他声部及时补入。

| 谱例 | 原谱与教学位点 |
|---|---|
| B-574 | C 大调两组，原标 T(7)–S、T(9)–T。最高音分别 C5–B4–A4、E5–D5–C5。中间 B4 或 D5 取二分，低部延长以衬托经过的七音或九音。第一组从 T 的 G3 与 C3 出发，S 下方两枚并排全音符的中心都在低谱第二线上，各奏 F3，男高下行、低音上行在同度相遇。此时上谱另有 A4 与 C4。第二组低音 C3 跨格连线。 |
| B-575 | C 大调，四个 3/4 小节，以属骨架和持续低音示范。上声部 G4–A4–B4 或 D5–C5–B4 时，低谱上行或下行箭头显示原声部的 B3 让出属三音，目标分别取 G3 或 D4。 |
| B-576 | C 大调，3/4。三组都保留 B4–A4–G4。首组原标「不好」，B4 离开后不补属三音。其余原标「正常」并列两条路径，箭头由 B 所在处指向内声补入的位置。 |
| B-577 | 海顿弦乐四重奏 Op. 76 No. 5 终乐章，D 大调，Presto、2/4。上下均用高音谱号。上声部十六分与八分跃入并下行，低声部反复八分音型，原谱三处有括注「(3)」。书中用快速织体说明省略或加倍三音在这些短时点上影响较小。 |
| B-578 | 两组均有 B4–A4–G4。首组原标「不好」，女低 G4 持续，女高到 G4 汇成同度。后组原标「正常」，女低下移至 D4，低部重新配置。教材另允许在汇合之前把妨碍音移开。 |
| B-579 | C 大调。D₇ 中上方出现 D5–E5–F5 时，左组箭头显示原七音移开，可与五音换位。右组原标 D₇–₉–T，原七音可以改往九音，再级进解决到下一三和弦五音。对照谱中的括注低位音和声部箭头。 |

## B-580–584 · 七音暂重、平行五八度及节奏交替

印刷第 264–265 页（PDF 260–261）。

| 谱例 | 原谱与教学位点 |
|---|---|
| B-580 | 格林卡歌曲《В крови горит》，B♭ 大调，Allegro passionato、3/8。箭头标上声部经 C5–D5–E♭5 到 F5，低音在 D₂–T₆ 时由 E♭3 下行 D3。两个 E♭ 同时出现时，原七音下行解决，旋律经过音继续上行。 |
| B-581 | C 大调三对对照，а 为 S–D，б、в 为 T–S₆。原谱用弧线和数字依次指出 5、5、8。比较每组左半的骨架和右半加经过音后的同时音程，隐藏的完全音程会变成连续的完全音程。 |
| B-582 | 三组对应改写。а 用 S–D₇，示范改低谱配置或让上谱内声先级进。б 提供 T–S₆、T₆–S₆ 或 T–TSVI，可变更首和弦转位、重音配置或更换到达和弦。в 对照 T–S₆ 与 D–D₆₅。教材也允许删换无法妥善保留的经过音。 |
| B-583 | C 大调，2/4。上声部在连续八分中 E5–F5–G5–A5，再到 B5–C6–D6，随后回 G5。女低 G4 连续跨格。教材允许活跃的女高在短时间内与女低相距超过八度。 |
| B-584 | 无调号，6/8，两格四部。前半拍组低音 C3–D3–F3 三枚八分，F3 延至第二格。低音趋缓时高声部接八分级进，让连续运动在声部之间交替。第二格起点的两个符头横向错开，低音 F3 下符干连梁，男高 G3 独立上符干。 |

B-584 的四部读数如下。第二格男高首个 G3 的附点可在上符干右侧辨认，按附点四分录。点为附点，`~` 为同音延续。

~~~text
S G4q. A4e B4e C5e | B4q. C5e D5e E5e
A E4q G4e F4q. | D4q F4e E4q G4e
T C4q. C4q A3e | G3q. G3q C4e
B C3e D3e F3e F3q.~ | F3e E3e D3e C3q.
~~~

教材一般把换和弦安排在强或相对强的位置，使活跃线条有稳定的和声节奏。若弱拍另换和弦，后续较强位通常再换一次。派生题可指定一个较慢的低音拍组，把接续的经过运动交给女高或内声。检查时逐个比对所有两声部在相邻时点的完全五、八度。
