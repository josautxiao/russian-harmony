# 教材 B · 主题 41 · 半音经过音

来源为杜波夫斯基、叶甫谢耶夫、斯波索宾、索科洛夫合编《Учебник гармонии》，1965 年版，印刷第 280 页（PDF 276）末起。

教材把半音经过音放在大二度相隔的两个自然音级中间，可用弱位或相对强位。端点可都是和弦音，也可一端为另一个经过音。数声同动时仍可用三度、六度、密集六和弦和四六，或混合方向。各声经过时可能短暂叠成经过音响，分析时用出发和抵达的和声确定功能。

## B-613 · 半音经过的四部与原印叉号

印刷第 281 页（PDF 277），C 大调、4/4。S、A、T、B 从高至低，w、h、q、e 是全、二分、四分、八分。× 记录原印叉号，最后一个交叉记号在扫描中接近直立加号。

~~~text
а，T–S
S G4q G♯4q A4h
A E4h F4h
T C4w
B C3h F3h

б，首拍原标 T
S C5e C♯5e× D5e× D♯5e× E5e D♯5e× D♮5e× D♭5e× | C5w
A E4q F4e× F♯4e× G4e F♯4e× F♮4q× | E4w
T G3h C4q G3q | G3w
B C3h C3h | C3w
~~~

б 第 2 拍女高 D5、D♯5 与女低 F4、F♯4 同向，第 3 拍后半 D♯5 与 F♯4 同时回落。女高折返段按谱保留 D♯5–D♮5–D♭5，女低同段为 F♯4–F♮4；两个谱内还原号各自作用于该线。

## B-615、B-616 · 半音拼写的和声依据

印刷第 282 页（PDF 278）。下表为可直接对照移调的柱式，从低到高列音，功能箭头沿用原印。完整旋律音列见本章上方。

| 方向 | 旋律位置 | 原谱音响和去向 |
|---|---|---|
| 上行 | C♯4→D4 | A2–E3–G3–C♯4 → D3–F3–A3–D4，原标 D→SII |
| 上行 | D♯4→E4 | B2–F♯3–A3–D♯4 → E3–G3–B3–E4，原标 D→DTIII |
| 上行 | 括注 E4→F4 | C3–G3–B♭3–E4 → F3–A3–C4–F4，原标方括注 D→S |
| 上行 | F♯4→G4 | D3–A3–C4–F♯4 → G3–B3–D4–G4，原标 D→D |
| 上行 | G♯4→A4 | E3–B3–D4–G♯4 → A3–C4–E4–A4，原标 D→TSVI |
| 上行 | A4–B♭4–B♮4 | B♭4 处以 G3–C4–E4 为下三声，原标方括注 D→S。随后 B 带还原号 |
| 下行 | G4–F♯4–F♮4 | F♯4 处为 D3–A3–C4–F♯4，原标 DD；F♮4 处为 G3–B3–D4–F4，原标 D |
| 下行 | E4–E♭4–D4 | E♭4 处为 F♯2–A3–C4–E♭4，原标 DDVII₇；D4 处低音转到 G2，原标 D |
| 下行 | D4–D♭4–C4 | D♭4 处为 E2–G3–B♭3–D♭4，原印导七箭头指向 S；末音处低音 F2 |

教材的解释由临时音在可能的和弦中的身份出发。上行的 C♯ 与 D♯ 分别趋向 D 与 E；A 到 B 之间用降 VII，示范可接下属的 C 属七拼写。下行 G 与 F 间用 F♯，可在 D 属七中成立；原谱下方另列「降 V」思路的两种反推音响，并以问号标示去向。移调时可先保留表中功能，再比较同键异名的指向。

小调上行沿用关系大调的拼写，下行沿用同主音大调。派生题可设同样跨度的上、下行，先标出两端音的功能，再按实际方向拼写经过音，并解释为何大调第 VI 与 VII 级之间取降 VII，或 V 与 IV 级之间取升 IV。

## B-617 · 平行半音线的异名拼写

印刷第 283 页（PDF 279）。雷格尔 Op. 45 No. 4，Allegro，谱标 C 大调，6/8。右手反复短双音，在 C5/G4、D♭5/A♭4 一类对齐的双音上维持谱面的平行轮廓，低声部穿插八分和变音。比较第一格两枚同位置降号和第二格的还原、升号。教材允许按照多个声部的平行关系改写等音拼写。同页还归纳小调的两向半音音阶拼写一致，降 II、升 III、IV、VI、VII。

口头题分析肖邦练习曲 Op. 10 No. 2 和里姆斯基-科萨科夫《萨尔坦沙皇的故事》中的《野蜂飞舞》的经过音。
