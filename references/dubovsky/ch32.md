# 教材 B 主题 32 · 离调与半音体系

印刷第 214–223 页（PDF 210–219），起于第 214 页下部。原书把离调后的副主音保留为原调的一个功能支点。副调未形成独立的完全终止，随后可回原调或走向其他副调。构造方法可用副属 D、D₇、DVII₇，或副下属 S、SII、SII₇ 等。原谱「+」标减三和弦。教材说这类不稳定和弦通常不作暂时的主。

## B-477–478 · 大、小调的副属与副下属

印刷第 215 页（PDF 211）。原谱用不同形状的符头区分辅助手段及其目标，中间的弧线表示联系。下表以低至高的音名列三和弦，功能字母沿用原谱。

### B-477 · 副属

| 原调 | 原标 | 引入和弦 → 副主 |
|---|---|---|
| C 大调 | D→SII | A–C♯–E → D–F–A |
| C 大调 | D→DTIII | B–D♯–F♯ → E–G–B |
| C 大调 | D→S | C–E–G → F–A–C |
| C 大调 | D→D | D–F♯–A → G–B–D |
| C 大调 | D→TSVI | E–G♯–B → A–C–E |
| a 小调 | D→dtIII | G–B–D → C–E–G |
| a 小调 | D→s | A–C♯–E → D–F–A |
| a 小调 | D→D | B–D♯–F♯ → E–G♯–B |
| a 小调 | D→tsVI | C–E–G → F–A–C |
| a 小调 | D→dVII | D–F♯–A → G–B–D |

### B-478 · 副下属

| 原调 | 原标 | 引入和弦 → 副主 |
|---|---|---|
| C 大调 | s→sII | G–B♭–D → D–F–A |
| C 大调 | s→DTIII | A–C–E → E–G–B |
| C 大调 | S→S | B♭–D–F → F–A–C |
| C 大调 | S→D | C–E–G → G–B–D |
| C 大调 | s→TSVI | D–F–A → A–C–E |
| a 小调 | S→dtIII | F–A–C → C–E–G |
| a 小调 | s→s | G–B♭–D → D–F–A |
| a 小调 | s→D | A–C–E → E–G♯–B |
| a 小调 | S→tsVI | B♭–D–F → F–A–C |
| a 小调 | S→dVII | C–E–G → G–B–D |

两例 C 大调均另列主三和弦及 B–D–F 减三和弦。a 小调另列主三和弦、B–D–F、G♯–B–D，在两个减三和弦上都印「+」。B-478 下方正文说副下属常经属到副主，也允许以 S 或 SII 三和弦组成变格 S–T。表中箭头代表目标和弦，不限定作品实际用一拍直进。移调和出题时应保留副主的三和弦性质，再计算副属导音或副下属成员。

## B-479–485 · 作品中的副属与副下属

印刷第 215–217 页（PDF 211–213）。教材把自然音调的和弦、以及可附于各功能的副属和副下属合称「半音体系」。

| 例号 | 作品、调性和拍号 | 原谱教学位点 |
|---|---|---|
| B-479 | 贝多芬 Op. 14 No. 2，Andante，C 大调、4/4 | 括线横跨弱位的 `D₄₃` 到强位 `TSVI`。谱面 G♯ 把 E 七和弦指向 a 小调临时中心，下谱还有休止。 |
| B-480 | 里姆斯基-科萨科夫《萨尔坦沙皇的故事》终场合唱，Allegro assai，G 大调、2/4 | `T–T₆–S–D₄₃→SII–D`。上谱 G♯ 向 A，小调 II 级作为局部落点，随后回属。本例与 B-479 的副主级别不同。 |
| B-481 | 格里格《森林之歌》（Лесная песнь），Allegretto，B♭ 大调、6/8 | 原标 T、DTIII、`D→S`、两次 `D→TSVI`、DD、D₇、T。数次短副属出现后终止仍在 B♭ 大调。连线及低谱升降记号标出每组范围。 |
| B-482 | 门德尔松《仲夏夜之梦》婚礼进行曲，Allegro vivace，C 大调、alla breve | 原标 `SII₆₅+D → DTIII`，继以 `SII₆–K₆₄–D₇–T`。页中两段括线把临时副属指向、总体收束分别标出。原首标的加号按版面保留。 |
| B-483 | 穆索尔斯基《霍万兴那》，Andante non troppo，e♭ 小调、alla breve | 以 `s(SS)→s` 示范经重下属的副下属。留意临时还原、高部保持和后接 `t–dVII–D–t`。 |
| B-484 | 利亚多夫《Про старину》，Allegro，D 大调、5/4 | `T–S(SS)→S–D–T`。低谱临时还原、高部连线标出重下属，原主在短末格回归。 |
| B-485 | 格林卡《鲁斯兰与柳德米拉》，Allegro，A 大调、4/4 | 原标 `D` 后有 `Ds→SII` 括线，后标 TSVI。看同音重复、临时记号以及中声部在休止前后的延留。 |

B-482 首标周围括线与 B-485 的 `Ds` 属原书功能标法。引用分析时应保留编号、句内位置与原符号，再按需要另释。

## B-486–487 · 离调的声部进行

印刷第 217–218 页（PDF 213–214）。教材列出三条要求。共同音保持，半音变音交给同一声部，重复音在另一声部通常反向走全音或半音。原书还允许低音有时以三度离开重复音，内声这样处理是例外。以下区分所见的谱面音与原书括线、虚线及箭头。

B-486 的六格分 C 大调、c 小调两行。下表只列出局部副属起音到副主落点，按 S/A/T/B。右栏的箭头是原谱有意突出的线条。

| 原调 | 原标及副调 | 四部起音和声部位点 |
|---|---|---|
| C | D₄₃→TSVI（a 小调） | G♯4/D4/D4/B2 → A4/E4/C4/A2。看女高 G4–G♯4–A4，低音 C3–B2–A2。 |
| C | DVII₇→SII（d 小调） | B♭4/G4/E4/C♯3 → A4/F4/F4/D3。男高稍后到 D4，低音同一声部 C3–C♯3–D3。 |
| C | D₄₃→DTIII（e 小调） | B4/A4/D♯4/F♯3 → B4/G4/E4/E3。高部跨短内声伴随音，男高 D4–D♯4–E4。 |
| c | D₂→tsVI₆（A♭ 大调） | B♭4/G4/E♭4/D♭3 → A♭4/A♭4/E♭4/C3。看低音 E♭3–D♭3–C3。 |
| c | D₂→s₆（f 小调） | E♮5/G4/C4/B♭3 → F5/F4/C4/A♭3。印刷下谱 B♭3 稍后进入，女高 E♭5–E♮5–F5。 |
| c | DVII₇→DTIII（E♭ 大调） | C♭5/F4/A♭3/D3 → B♭4/G4/G3/E♭3。女高 C5–C♭5–B♭4，次高部末有额外 E♭4。 |

第二行第 1 格落点的空心 A♭4 由上、下两根符干共用，女高和女低各持二分。第 3、5 格表列的是相关和弦内的音位，个别低谱和上谱不是同拍起音，制谱时应参看原图。

B-487 是 C 大调的补充四格。前两格同样在不同声部处理 C–C♯，原箭头分别指高位低谱和最低声部。以下列各格的半音位置与方向。

| 格 | 原谱指示与可核音位 |
|---|---|
| 1 | 女高 E5、女低 G4 保持，男高 C4→C♯4，低音 C3→A2，继而向回。这里的低音以三度避开半音加倍。 |
| 2 | 低音 C3→C♯3→D3，男高 C4→A3 反向移开，原箭头画在下谱两条线旁。 |
| 3 | 上方箭头标向上运动，最低声部及邻接内声向下。第二击女高 C♯5、女低 A4、男高 E4，低音为 A3。 |
| 4 | 原标 S–K₆₄–DVII₇–TSVI。向上和向下箭头引到 TSVI，右括注称阻碍终止的特殊变体。 |

第 218 页（PDF 214）B-487 原谱未另印拍号，按各组所写四分、二分分列，q 为四分，h 为二分。本例第三组和第四组倒数第二击的下谱高音按符干分配。

~~~text
第 1 组
S E5q E5q D5q
A G4q G4q F4q
T C4q C♯4q A3q
B C3q A2q D3q

第 2 组
S G4h F4q
A E4h D4q
T C4q A3q A3q
B C3q C♯3q D3q

第 3 组
S C5q C♯5q D5h
A G4q A4q A4h
T E4q E4q D4h
B C4q A3q F3h

第 4 组
S F5q | E5q D5q | C5h
A C5q | G4q F4q | E4h
~~~

正文补充，离调中较常用非终止性质的副属转位，主音落点常在比副属更强的拍位。也有更长或多次的离调，正文参照舒曼《Grillen》Op. 12 与 B-481。作业检查时先从哪一声部开始半音变化，追到该声部的目的音，再检查同音是否保留及重复音是否反向移开。

## B-488–490 · 乐段中的离调位置

印刷第 218–219 页（PDF 214–215）。原书以首尾回到同一主调来认定整体上的单调乐段，中间可有多次离调。大调中段常指向 D，其次 TSVI、DTIII，终止附近常见 S、SII。小调常指向 dtIII、d、D，终止附近可见 s、tsVI 或低 II。下属方向也可在句首出现。

- B-488，里姆斯基-科萨科夫《五月之夜》，Moderato，d 小调、2/4。谱下 `DVII₇→s | DVII₆₅ | t`，上方成对八分与下方临时升号对应。开头很快指向 g 小调下属，随后以原属组回 d 小调。末格的括注和弦照印刷保留，供听辨末句的目标。
- B-490，阿连斯基《夜》（Ночь），Andante sostenuto，G 大调、4/4。第一行原标 T、`D→SII`、D₉。第二行 `T–D→DTIII`，再有 `D→TSVI:SII（D-dur）–D₇–T`。教材末段用括线圈定 D 大调，以某处 TSVI 重新理解为 D 大调的 SII，再落属和主。可分别跟读两段高低声部的八分出入和末段高低两层三连音。标出的目标和弦出现后仍应结合作品的句界判断离调和转调。

### B-489 · 变格式离调的三组写作示范

印刷第 219 页（PDF 215），C 大调。首组在 E3 低音的 D₆₅ 后到 F3 上的 S，旋律 C5 跨三格保持。第二组用 G2 起音后转为 C3 持续。第三组原标 `T–D→SII`，男高 C4–C♯4 和女高 C5–B♭4 同时对置，低音 C3 跨格保持。q、h 分别为四分、二分，~ 为同音延长。

~~~text
第 1 组
S D5q D♯5q | E5q B4q | C5h~ | C5h~ | C5h
A A4h | G4q F4q | E4q G4q | F4q D4q | E4h
T C4h | C4q D4q | C4q B♭3q | A3q A♭3q | G3h
B F3q F♯3q | G3h | C3q E3q | F3h | C3h

第 2 组
S D5q | C5h~ | C5h~ | C5h
A F4q | E4q G4q | F4h | E4h
T B3q | G3q B♭3q | A3q A♭3q | G3h
B G2q | C3h~ | C3h~ | C3h

第 3 组
S C5q B♭4q | A4q A♭4q | G4h
A E4h | F4q D4q | E4h
T C4q C♯4q | D4q B3q | C4h
B C3h~ | C3h~ | C3h
~~~

原谱第 2、3 组都用持续低音。选作移调或原创对照时可先沿用第一组的低音进行，再把第二次旋律配成第三组那样的持续低音，并保持副属的临时升音及女高的下降方向。

## B-491–492 · 阻碍进行和从目标反推的配法

印刷第 220–221 页（PDF 216–217）。正文列 `D—D→S(SII)`、`D—D→TSVI`，小调也可 `D→dtIII`。以先到原属、后把属的进行转入另一个调的非稳定和弦组成阻碍进行。回看 B-487 末两格可听到终止四六后所谓升高原属根音，实际作为到 VI 的副导七。

B-491а、б 各先列单声部给定，再列四部结果。先从重拍的目标音找临时主和弦中的根音、三音或五音，再找合适的副属或副下属，最后检查前面接得是否平稳。

| 格 | 单声部骨架与结果 |
|---|---|
| а | 第一格 C5–D5–E5，第二格 F5–E5–D5。括线给副属到 SII 的位置。四部结果把第二格低音写成 F3–G3–F3，内声临时 C♯ 后接 D，原标 `D₂→SII₆`。 |
| б | 弱起上方 E5–C5，次格 D5–G4–A4。给定谱下标 `D₆ s₆+D→SII`；四部结果保留低谱 B♭ 和 C♯ 的变化，最后落 II。第一组下方的加号、括线与首转位符号按原书保留。 |

B-491а 两格四部结果逐声部如下，`q h` 是四分与二分。第一格给定旋律三个四分，第二格末音为二分。

~~~text

A G4q G4h | A4q A4q A4h
T C4q B3q C4q | C4q C♯4q D4h
B E3q D3q C3q | F3q G3q F3h
~~~
