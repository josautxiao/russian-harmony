# 教材 B 主题 7 · 和弦三音之间的跳进

印刷第 43–45 页（PDF 39–41）。在四、五度根音关系的 T–D、D–T、T–S、S–T 采用和声连接时，女高或男高可以把一个和弦的三音跳到另一个和弦的三音。女高在跳进两端的较高音用开放、较低音用密集。男高规则相反，较高音用密集、较低音用开放。通常女高跳进后的旋律反向。教材允许特定趋向音顺势解决，并规定小调主三音至大属三音走下行减四度。以下四部配置按女高、女低、男高、低音。

## B-082 · 女高的三音跳进

印刷第 43 页（PDF 39），C 大调。每组最初两格上方各印 3，以线指示跳进的两个声部位置。表列全部和弦起点，保持音在原图可跨几个起点。第一组女低 G4、第二组男高 G3、第六组女低 C4 各保持三拍。第四组有四次起点，男高前两拍保持 G3，女低后两拍保持 C4。第七组女低 C4 保持前两拍。

| 组 | 功能 | 四部配置依次 |
|---|---|---|
| 1 | T D T | E5/G4/C4/C3 → B4/G4/D4/G2 → C5/G4/E4/C3 |
| 2 | T D T | E4/C4/G3/C3 → B4/D4/G3/G2 → C5/E4/G3/C3 |
| 3 | D T D | B4/G4/D4/G3 → E5/G4/C4/C3 → D5/G4/B3/G2 |
| 4 | D T S T | B4/D4/G3/G2 → E4/C4/G3/C3 → A4/C4/F3/F2 → G4/C4/E3/C2 |
| 5 | T S T | E5/G4/C4/C3 → A4/F4/C4/F2 → C5/G4/E4/C2 |
| 6 | T S T | E4/C4/G3/C3 → A4/C4/F3/F3 → G4/C4/E3/C3 |
| 7 | S T D | A4/C4/F3/F2 → E4/C4/G3/C3 → G4/D4/B3/G2 |
| 8 | S T D | A4/F4/C4/F3 → E5/G4/C4/C3 → D5/G4/B3/G3 |

## B-083 · 男高的三音跳进

印刷第 44 页（PDF 40），C 大调，3/4。每拍一个和弦起点。前两拍的男高音均标 3。第二、四组女低 G4 用附点二分。第三组女高 C5 保持前两拍，女低 G4 保持后两拍。

| 组 | 功能 | 四部配置依次 |
|---|---|---|
| 1 | T S T | C5/G4/E4/C3 → C5/F4/A3/F3 → C5/E4/G3/C3 |
| 2 | T D T | C5/G4/E4/C3 → D5/G4/B3/G3 → E5/G4/C4/C3 |
| 3 | S T D | C5/F4/A3/F3 → C5/G4/E4/C3 → B4/G4/D4/G3 |
| 4 | D T D | D5/G4/B3/G3 → C5/G4/E4/C3 → B4/G4/D4/G3 |

## B-084 · 女低跳三音的反例

印刷第 44 页（PDF 40）。原标「не хорошо」。T–D 的 E4→B4，S–T 的 A4→E4，由女低跳到另一和弦三音，造成教材所指的不当排列。

| 功能 | 配置 |
|---|---|
| T–D | C5/E4/G3/C3 → D5/B4/G3/G2 |
| S–T | F5/A4/C4/F3 → G5/E4/C4/C3 |

## B-085 · a 小调八小节四部示范

印刷第 44 页（PDF 40），2/4。音高按和声起点列出。括线标三处三音跳进。女高在第 1 小节末到第 2 小节首 G♯4→C5，第 6 小节 F5→C5。男高在第 2 小节末到第 3 小节首 G♯3→C4。两处 G♯→C 是属三音回主三音的上行减四度。
