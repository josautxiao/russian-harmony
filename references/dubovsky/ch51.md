# 教材 B · 主题 51 · 调性关系的程度及相差两个升降号的转调

来源为 1965 年版《Учебник гармонии》，印刷第 350 页（PDF 346）下段起。教材以主和弦间的功能关系以及共有和弦划定第一至第四关系。调号之差是初步线索，还要核对大小调的不同形态及共有和弦。例如 C 大调和 d 小调的调号差一个，C 大调与 F♯ 大调、e♭ 小调的调号差六个。

## 第一至第四关系

印刷第 351 页（PDF 347）。C 大调与 f 小调虽然调号相差四个，教材将两者列为第一关系。C 大调与 f♯ 小调虽只差三个，却归入第四关系。各级按教材体系给出，起始调不计入数目。

| 级 | 每个出发调的数量 | 依据 |
|---|---:|---|
| I | 6 | 主和弦属彼此的近关系范围，并有多项共同和弦。教材在大调计入小下属调，在小调计入大属调。 |
| II | 4 | 调号相差两个，两调有两个共同的自然音三和弦，两者都不是起始调或目的调的主和弦。 |
| III | 8 | 教材依大小调混用及和声调式中出现的共同三和弦归组。 |
| IV | 5 | 自然与和声形态都没有共同三和弦。等音重写按一个调计。 |

**B-763、B-764**，印刷第 352 页（PDF 348），用每一调的主三和弦和调名列全表。椭圆圈中的全音符为出发调；其他大三和弦用空心有符干音符，小三和弦用实心有符干音符。下面统一使用中文调式和升降名，原印德语 B 是降 B，H/h 是 B 大调/b 小调。

| 关系 | B-763 从 C 大调 | B-764 从 c 小调 |
|---|---|---|
| I | G、F 大；d、e、f、a 小 | B♭、A♭、G、E♭ 大；g、f 小 |
| II | B♭、D 大；b、g 小 | D♭、F 大；b♭、d 小 |
| III | A♭、A、B、D♭、E♭、E 大；c、b♭ 小 | C、D 大；a♭、a、b、d♭、e♭、e 小 |
| IV | F♯〔G♭〕大；c♯、d♯、f♯、g♯ 小 | B、A、F♯、E 大；f♯〔g♭〕小 |

第 351 页第三关系的 c 小调文字列举少一项；第 352 页的 B-764 在第三行明确写出 des 小调，按图保留。第 764 号第四行的 B 大和 E 大和弦旁印了等音括号，仍计入各自单一调。

## 两个升降号的转调及中介

印刷第 353–355 页（PDF 349–351）。第二关系的两个共同三和弦是五度圈较偏升号一侧那个调的下属与其关系和弦。教材将中间和弦或短暂引入的中间调都视为转调支点，要求末调明确收束。多次连续转向第一关系调可组成渐进转调。第 353 页的文字路线有 C→F→g→E♭→f→D♭，以及 c→A♭→D♭→e♭ 或 c→f→D♭→e♭。选择中介时可以在同一调式和同方向四、五度的链条中穿插另一调式或不同音程；转调段较长时可使用两个中介。

**B-765**，印刷第 353 页（PDF 349）。八个双线隔开的两和弦小图，以下存原谱先后和功能。列音按低至高。第六格经放大确认，目标框确印小写 f，和弦下原印 sII、s。第 351 页正文与 B-764 均列 F 大调。该格 G–B♭–D 和 B♭–D–F 两个实际音响也是 c 小调与 F 大调的共同三和弦。表内调名据正文与总表，功能字形照录；以 F 大调重释时为 SII、S。

| 4 | C→g | S，F4–A4–C5 | SII，D4–F4–A4 |
| 5 | c→d | s，G4–B♭4–D5 | tsVI，B♭4–D5–F5 |
| 6 | c→F | sII，G4–B♭4–D5 | s，B♭4–D5–F5 |

**B-766**，同页。四格方框标端点，括线表相邻的中介关系。

| 格 | 谱面概要 |
|---|---|
| 1 | C 大三和弦 → G 大三和弦 → e 小三和弦 → D 大三和弦。 |
| 2 | C 大三和弦 → e 小三和弦 → 括号内 G 大三和弦 → b 小三和弦。 |
| 3 | c 小三和弦 → f 小三和弦 → A♭ 大三和弦 → D♭ 大三和弦。 |
| 4 | c 小三和弦 → D–F–A♭ 减三和弦 → A♭ 大三和弦 → b♭ 小三和弦。第二柱最低符头在下方 D4 音位，中声 F4，上声 A♭4。此柱下无调名框；其后三音 A♭4–C5–E♭5 与 b♭ 小调终点的柱式另以括线相连。 |

调性方案或钢琴即兴可以选择 C→e→D，先写 E–G–B 如何从 C 的 III 转作 D 的 II，再以 A₇→D 确立终点。若把中介调短暂当作主调，可以加 B₇→e，保留终点的正式终止。此处为从规则推导的练习材料。

## 作品和写作示范

| 谱例 | 原谱与教学位点 |
|---|---|
| B-767 | 印刷第 354 页（PDF 350），韦尔斯托夫斯基《阿斯科尔德之墓》，4/4，三系统。原标 G 大调→D 大调→A 大调，第一个 T=S 在第二系统第一格靠末，第二个 T=S 在第三系统开头的 D2 长音处。可把两个 T=S 分别理解为 G 和 D 的主三和弦改作下属。原谱以括线圈出 D 段，A 段最后低音 A2，印 T。两个 T=S 下方分别出现低谱 G2–D3 的八分双音、D2–D3 的二分八度。以低谱进入位置定位两次重释，再结合两条调名括线定位 D 大调与 A 大调段。开头人声式附点动机与下方分离的八分和弦伴奏在经过调继续。 |
| B-768 | 印刷第 355 页（PDF 351），贝多芬钢琴奏鸣曲 Op. 53，Allegro con brio，原框 e、C、F。进入 C 框的和声为 C3–E3–G3–E4，e 小调降 VI 改释为 C 大调主和弦。原印 tsVI=t，等号右侧确为小写 t，和实际大三和弦及大写 C 框同时保留。下系统 F 框处明印 T=D，以 C–E 的音响将 C 的主功能转为 F 的属功能。相似的两格节奏动机贯穿各段，第二系统后部高谱改用低音谱号。 |
| B-769 | 同页，肖邦 f 小调《幻想曲》，4/4，原框 C→B（B♭ 大调）。前两格印 D、D→S、SII₇、D、T=DD，后两格印 D、D→S、SII₇、D₇、T。C 的主和弦重释为 B♭ 的重属，随后 F 的属功能与 E♭ 下属组标出终点。末格的 D₇ 后以低谱 B♭1–B♭2 八度进入 T。前一中介 C 的 T=DD 写在 B♭ 框之前，目标调的 D 在框后另标。 |
| B-770 | 印刷第 356 页（PDF 352），里姆斯基-科萨科夫《隐城基捷日传说》，Moderato。教材标为简图，省去装饰音型。两系统方框 D→C→B（B♭），低谱先长时间连持 A2，再连持 G2。第一系统末印 T=DD；第二系统近末印 DD、T=DD，随后进入 B♭ 的方框。原调与中间调的主和弦可转为下一目标的重属。末柱 B 框高谱上端明写 B♭5，低谱最低符头为 F♮2，低谱中可分辨 F♯3、B♭3 和上方带还原号的 F♮4。F♯3 与 F♮4 分别印升号和还原号，密排的其余符头需照原页。 |
| B-771 | 同页，教材写作示范，F 大调调号、4/4，三系统。首行两八分弱起接两段相近的动机，低谱反复出现相同节型并借临时 B♮ 改变和声方向。第二系统逐次引入 G♯、D♯、F♯ 等变音并变换低音支点。第三系统前三格的 D3 全音符连至第四格开头的 D3 二分音符，随后低层换音。末格 G2h. 支撑高谱 G4h.、D4h.，低谱上声在末拍加 B♮3，确立 G 大调。原谱未框出中间调，四部完整归属和中介功能留复核。 |
| B-772 | 印刷第 357 页（PDF 353），《沃罗涅日州歌曲集》合唱《夜莺啊，小夜莺》，慢速，交替出现 2/4、3/4。原标 e 小调（领唱）→A 大调→e 小调；双谱均用高音谱号。开头两个 2/4 小节上谱整格休止，领唱从下谱 E4 出发。随后 3/4 格下谱为 E4–E4–A4 三个四分，上谱前两拍休止，到第三拍加入，紧接 A 大调标记与临时 C♯。第二系统的 e 小调标记处，下谱重奏 E4。末格在前置休止后以高谱 E5、E4 与低谱 E4 收束，原印延长号。教材用此说明旋律调式可使调号差两个升降号的调在实际听觉中直接连接。 |

第 355 页正文把第二关系转调主要放在中段、展开部或连续模进的调性发展之中。第 357 页还举 C 混合利底亚与 g 多利亚的自然音列重合为可直接连接的情形。
