# B补充：调性布局

来源：B主题59《Основные принципы построения тонального плана произведения》，印刷410–414页，PDF406–410；A相关内容散见主题34、39，不能说这一方法逐条出自A。

把调的出现顺序理解为曲式与发展过程，而非仅列调名。B提出常见的大方向是开端向属侧、接近结尾向下属侧再回主调，与一个局部完全进行的T–S–D–T顺序不宜机械等同；这是常见安排，不是所有作品的硬性法规。

1. 按主题与段落划分曲式，列主调、各局部调、到达时点、持续长度和巩固强度。
2. 区别离调、真正转调与并置，辨认展开或连接部中的较远调性及回归路径。
3. 将调性距离、方向、密度与主题发展、高潮、再现联系；不能只以调号远近定义表现力。
4. 反查每个调性判断的终止和旋律证据，允许存在竞争解释。

输出表：段落/小节｜中心｜到达方式｜终止证据｜在全曲中的作用。原创小型布局可研究C—G—a—F—C；这只是规划，不能在没有音乐内容时断言其已经成立。
