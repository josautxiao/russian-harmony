# 隐私与公开范围 · Privacy · Конфиденциальность

## 中文

公开内容仅包括技能文件、独立整理的知识、书目与主题页码、原创示意、项目文档和辅助检查代码。公开Git历史使用项目署名或GitHub公开用户名，配合GitHub隐私邮箱或项目占位地址，不使用维护者的私人邮箱。公开范围不包括聊天记录、原书与全文OCR、个人学习档案、健康或身份资料、私有文件编号、账户凭据或电脑绝对路径。

本仓库的检查脚本在本地读取文件，不上传文件、收集提示词或发送遥测。实际使用的AI宿主和GitHub是独立服务，其数据处理与账户公开设置不由本项目控制。GitHub仓库所有者用户名、公开资料以及未来贡献者自行提交的姓名、邮箱或内容可能公开可见；本项目不能保证匿名。

反馈问题时请先删去个人资料，不粘贴整段私人对话、访问令牌或账户截图。提交前检查文件内容与Git提交记录，而不只检查当前README。

## English

Public material is limited to skill files, independently organized knowledge, bibliography and topic/page references, original illustrations in text, documentation and supporting checks. Public Git history uses a project identity or a public GitHub username with a GitHub privacy address or project placeholder, rather than the maintainer's private email. It excludes private conversations, source books and full OCR transcripts, personal learning records, health/identity information, private file identifiers, credentials and absolute local computer paths.

The checking script reads local files without uploading them, collecting prompts or sending telemetry. AI hosts and GitHub are separate services with their own data practices and account visibility settings. The repository owner's username and public profile, and names, emails or content that future contributors choose to submit, may be publicly visible. This project cannot guarantee anonymity.

Remove personal details from reports. Do not paste private conversations, tokens or account screenshots. Inspect both file contents and commit history before submitting.

## Русский

Публикуются только файлы навыка, самостоятельно организованные знания, библиография и ссылки на темы/страницы, собственные текстовые примеры, документация и проверки. В публичной истории Git используются название проекта или публичное имя GitHub вместе с приватным адресом GitHub либо служебным адресом-заглушкой, а не личная почта сопровождающего. Личные беседы, исходные книги и полные тексты OCR, учебные досье, сведения о здоровье и личности, частные идентификаторы файлов, учётные данные и абсолютные пути компьютера исключаются.

Скрипт проверки читает локальные файлы, не загружая их, не собирая запросы и не отправляя телеметрию. ИИ-приложения и GitHub являются самостоятельными сервисами со своими правилами обработки данных и настройками публичности. Имя владельца репозитория, его открытый профиль, а также имена, адреса и материалы будущих участников могут быть общедоступны. Анонимность не гарантируется.

Удаляйте личные сведения из сообщений об ошибках. Не вставляйте частные беседы, токены или снимки учётных записей. Перед отправкой проверяйте и файлы, и историю коммитов.
