## 这是什么

“俄罗斯和声”是一份围绕俄罗斯四部和声教学传统整理的开放知识技能，供支持 `SKILL.md` 的 AI 助手按需读取。它将教材中的概念、连接方法、功能解释、终止与转调技术整理为分主题的操作规则，并保留不同教材之间的差异和出处。

它可以辅助学习、教学备课、习题分析与原创配和声；完整四部答案仍须根据实际音高、八度、节奏和上下文检查。它不是自动乐谱识别软件，也不是全部原书的翻译或习题答案集。

**当前语言范围：三个 README 分别提供中文、英文和俄文介绍；技能正文、主题与多数参考文件目前以中文为主，保留重要俄文术语。三个 README 不代表全部知识文件已经三语翻译。**

## 设计原则

- **一条清晰的教学主线**：以阿贝佐娃教材的绪论与41主题为顺序，便于循序渐进。
- **同类内容合并，差异保留**：将四位作者合编教材的60主题映射到主线，独有内容另列；不把两种解释强行改成一种。
- **规则能够回到出处**：同时标主题、印刷页与制作本版所用扫描件的PDF位置。
- **先判断，再选和声**：先规划句法、终止、调性目标和声部，再讨论局部配置。
- **区分规则与审美**：技术正确、教师要求、风格习惯与审美偏好属于不同层面。
- **按需读取**：入口负责选择任务与查找主题，详细内容分文件加载。

## 可以做什么

| 任务 | 典型用途 |
|---|---|
| 为旋律或低音配和声 | 先列功能方案，再实现带八度的SATB并检查连接 |
| 声部检查 | 定位平行五八度、交叉与超越、音域、重复、省略及倾向音解决 |
| 功能与终止分析 | 比较III、VI的功能口径，分析K64、阻碍进行和终止强度 |
| 离调与转调 | 说明局部中心、共同和弦、功能重释和新调巩固证据 |
| 术语学习 | 对照俄汉术语，澄清“三音跳进”“关系调”等常见歧义 |
| 教材比较 | 对同一问题分别引用A、B的解释和限定例外 |
| 教学与自主学习 | 按当前进度限制可用材料，生成明确标注的原创示例 |

## 来源与组织

| 标识 | 教材 | 本版作用 |
|---|---|---|
| A | Е. Н. Абызова：《Гармония》，Москва：Музыка，2008 | 绪论与41主题的主目录 |
| B | И. И. Дубовский、С. В. Евсеев、И. В. Способин、В. В. Соколов：《Учебник гармонии》，Москва：Музыка，1965 | 60主题的对应、补充与比较 |

B是四位作者的合著，不只归于斯波索宾个人。本版按扫描件书内信息记录年份；其他印次和扫描件的PDF偏移可能不同。

内容覆盖主三和弦与副级和弦、转位、七九和弦、终止、非和弦音、俄罗斯自然音调式、变音、离调、转调、持续音与大小调混合，另含A的二十世纪和声概览。B的调性布局、系统分析与综合习题训练方法放在补充部分。

参见[完整对照](references/source-map.md)与[机器可读索引](references/source-index.json)。这是一份按全部主题建立知识入口的提炼版，不是逐条穷尽每个谱例和稀见变体。

## 已保留的教材差异

例如，III、VI的功能解释、特定不完整属七结束终止中的八度例外、半音与转调模进的命名，以及调关系的三等级/四等级体系，都需要注明教材口径。

未指定教材时，技能默认采用A目录和较保守的基础习题规则；指定B或教师要求时切换口径，并说明依据。详见[差异表](references/differences.md)。

## 安装与开始使用

### 无需编程的方式

1. 在本仓库点击 **Code → Download ZIP**，解压。
2. 将完整文件夹命名为 `russian-harmony`；文件夹里应直接有 `SKILL.md`、`chapters/` 与 `references/`。
3. 放到AI宿主支持的技能目录。不要只复制入口文件。
4. 重新查看宿主的技能列表；必要时新建会话或重启宿主。

| 宿主 | 常见个人技能目录 | 常见显式调用 |
|---|---|---|
| Codex | `~/.agents/skills/russian-harmony/` | `$russian-harmony` |
| Claude Code | `~/.claude/skills/russian-harmony/` | `/russian-harmony` |

`~` 表示当前用户的主目录。Codex项目级也可使用 `.agents/skills/russian-harmony/`。其他支持Agent Skills结构的宿主需按其文档安装；本项目没有宣称已逐个实测所有宿主。安装前若已有同名目录，先备份或比较，不要直接覆盖自己的修改。

### 使用Git的方式

将整个仓库克隆到Codex的个人技能目录：

```bash
git clone https://github.com/josautxiao/russian-harmony.git ~/.agents/skills/russian-harmony
```

Claude Code用户将目标目录换成 `~/.claude/skills/russian-harmony`。正常使用提炼规则不需要运行OCR、不需要安装Python包，也不需要原转换器。涉及原谱或原书题时，需要自行取得有权使用的对应教材。

普通聊天界面不一定支持安装Skill；上传几个文件也不等于已获得跨会话自动调用能力。请以所用宿主的实际功能为准。

## 提问示例

```text
使用 $russian-harmony，按A主题16解释属七的转位。
给一个原创四部示例，写出各声部的八度，并检查六对声部。
```

```text
使用 $russian-harmony，比较两本教材对VI级和弦的功能解释。
区分共同规则、不同口径和当前例子的推导，并标注出处。
```

```text
使用 $russian-harmony，检查我提供的四部和声。
先指出具体时点、声部和音高，再给最小修改；不要擅自改变给定旋律。
```

请尽量提供：题目的调号、拍号、音符与时值、声部八度、给定旋律或低音，以及允许使用到哪一主题。可以要求用其他语言回答，但知识文件本身目前并非完整三语版本。

## 质量与限制

制作初版时，两份扫描件共824个图像单元完成文字OCR；运行完成不等于识别准确。原书谱例的音符、节奏、上下标、变音与数字低音不能只凭普通OCR重建。

- 原书题面、谱例及细节争议需要返回原页核对。
- 罗马数字序列只是功能方案；完整答案还需要音高、八度、时值及逐声部检查。
- 初版做过结构检查、链接检查、主题覆盖核对、独立试用和原创四部范式检查。这些不保证所有规则或未来答案都无误。
- 仓库检查只验证结构、出处入口与公开内容范围，不自动判定音乐正确或法律权利。

详见[OCR与核验要求](references/ocr-quality.md)。发现问题欢迎提交Issue或Pull Request，请提供最小例子与准确出处。

## 如何更新与贡献

新增教材时保留现有主线、补充主题映射、合并共同规则、保留分歧；新增教师经验时注明指导者、适用范围、优先级、例外与原创例子。未经确认的审美偏好不要变成全局硬规则。

具体流程见[CONTRIBUTING.md](CONTRIBUTING.md)，版本记录见[CHANGELOG.md](CHANGELOG.md)。如果通过Git安装且没有本地修改，后续可在安装目录运行 `git pull --ff-only`；有自己的修改时先备份或使用分支。
